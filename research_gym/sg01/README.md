Run python research_gym/sg01/native_trace.py native-dev.jsonl --dose-tolerance 0.01 (freeze tolerance prospectively). Failed checks block scoring, never silently drop rows. At least 59 independent development units for distribution-free 95/95 sham tolerance; register equal-k geometry-free, shuffled geometry, matched sham and random orientation controls.
