# KITE-JOINT-02: budgeted seven-player strategic search and partial regret certificates

Status: development-only synthetic pilot. Independent unit is generated payoff world (48, 12 per family). Shared seed across arms; repeated candidate evaluations are not replications. All arms start from the same pure joint profile. Fixed 256 unique payoff-cell budget per arm, zero initial cache, 12 rounds. BR follows the highest-regret player's exact best response, retains best certified state, stops on cycle. Pure descent evaluates unilateral pure best-response proposals and chooses strict lexicographic max-regret / sum-regret improvement. Mixed descent evaluates the same pure candidates plus 1:1, 3:1, 1:3 mixtures of the modal current action and best response, at most two mixed players, with identical strict descent selection. Proposal ordering deterministic by current regret then player index; evaluate pure then blends per player. This is query-budget parity, not FLOP/time parity; actual consumed cells differ. All comparisons report raw paired regret; no significance claims, sealed holdout, calibration, native engine execution, or convergence guarantee. No KITE repair for general multiplayer. Exact global regret only for declared action rosters.

Partial certificates: with integer strategy weights w_i and totals S_i, each unilateral action b's signed expected-utility gain has coefficient (S_i 1[a_i=b]-w_i[a_i]) prod_{j!=i} w_j[a_j] on the payoff cell a, normalized by D prod_i S_i. For unknown cells the lower contribution is min(0,c D) and upper max(0,c D); known cells contribute exactly. This cancels identical own-action terms and supplies a sound max-regret interval even before the frontier is complete. A positive threshold is certified when the upper bound is <= threshold, refuted when lower exceeds it; otherwise unknown. Upper and lower tighten monotonically with more receipts; fully observed frontier collapses to the exact result. Lower bound is conservative across competing deviations. Unknown native engine cells are never imputed. Current search uses only complete frontier certificates for selection, not these partial bounds. No oracle authentication claim: hashes are receipt shape checks.

Pilot receipt includes all selected and evaluated profiles, exact returned certificates, and every unique payoff cell. Replay with node run_joint_search.mjs; native engine adapter still needed for this adaptive search. The existing native fixed-profile mixed audit remains separate and untouched.
