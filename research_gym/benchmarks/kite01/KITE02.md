# KITE-02: prospective pilot of a learned multiscale router

Freeze source and protocol before training; commit training checkpoint before reading test results. Seeds are public and deterministic; this is a prospectively specified pilot, not a third-party-sealed confirmation. No prior test scores accessed.

Independent unit: generated game root. 108 train roots (3 families x 3 sizes x 12); 96 fresh test roots (4 families x 3 sizes x 8); block_cycle family withheld from training. Each action is the unique best response to some pure opponent action, checked at generation, so cannot be weakly dominated by a mixture of other actions. Sizes 6/10/14; irreducibility to dominance and clone removal does not imply hardness for all solvers. Three model initialization seeds; fixed primary 719; others sensitivity only. Depths and seeds share root units.

Model: 29-dimensional permutation-invariant features of memory distributions and previous exact regret, shared 8-unit tanh hidden layer and 5-way recipe head (285 parameters). Recipes: full history with normalized prior, windows 4/16/64, uniform mixture of all four. Teacher computes exact regret for every recipe, converts to soft targets exp(-regret/0.04), trains on 3 exploration trajectories per root, 30 epochs of SGD. Training queries counted. Learned router picks argmax without candidate search at inference. Small factorized router inspired by BPD, not a native BPD decomposition or trained TRM. Teacher uses myopic regret feedback.

All arms compute same bank and model forward before selecting recipe. Full, each window and uniform are fixed controls. Shuffled arm replaces selected route by a random different recipe at each step (matched forward and one selection, destructive sham, uncalibrated). Oracle scores all five recipes, a greedy one-step selector with 5x best-response budget and no trajectory optimality guarantee. Exact strategy profiles and regrets recorded. Same deterministic tie rule. At depth t all arms except oracle use 2*(t+1) solver queries. Repair checks separately counted. BigInt verifier, floating-point training; no measured wall-time match. No best-so-far selection.

Primary endpoint: raw maximum regret <=0.05 at depth 8, learned vs uniform and learned vs shuffled (two planned comparisons); meaningful gain >=5 percentage points. Report paired discordances, effect and mean regret reduction. Depths 4/16/32, other thresholds/families/arms and seed sensitivity descriptive. No causal or generalization claim until EvalMath FSI gates, measured matched-sham floor, pre-data resolution and independent sealed model/game roots. 96 test roots may be insufficient for conservative effect floor. No post-hoc switching of primary seed or threshold.

Replay: node train02.mjs > router02_checkpoint.json ; node eval02.mjs router02_checkpoint.json > router02_receipt.json. Exact KITE-01 tests unchanged.
