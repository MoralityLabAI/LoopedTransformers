# KITE-03: terminal-regret residual routing

Pre-data freeze; training and calibration checkpoints will precede evaluation. This is a publicly seeded prospective pilot, not independent sealed confirmation.

Units: 72 train roots (3 families, sizes 6/10/14), 60 development roots (4 families, sizes 8/12/16), 120 new test roots (5 families, sizes 8/12/16). Ring family withheld from both training and development; other families derive from KITE-02 with disjoint seeds. Model seeds 613 (primary), 1231, 8731 (sensitivity, same game roots).

Model: shared 35-input/12-hidden/5-output tanh residual router, 497 parameters (420+12+60+5). Fixed recipes full, recent 2/4/8/16, equal mixture. For each training state (two exploration paths per root, six checkpoints), estimate each recipe's terminal effect after four updates: first candidate recipe chooses both best responses, remaining updates use full history, terminal readout full history. Learn scaled signed regret reduction relative to full using MSE; no test data or candidate lookahead at inference. Policy selects an alternative only when predicted gain exceeds margin. All recurrence arms except uniform_direct return normalized full-history readout, including fixed uniform; recipe influences best-response update only. Add uniform_direct as a separate fixed comparator matching KITE-02's multiscale readout; it uses the uniform bank for both updates and final readout. Include it among fixed recipes in development selection. This changes KITE-02's readout contract. Baseline full keeps one total pseudocount. Distinct windows at sufficiently long depths.

Development only: choose margin from 0/.005/.01/.02/.04/.08/disabled by mean terminal regret at depth 32, deterministic first-min tie break. Tune projected extragradient (EG) and optimistic multiplicative weights (OMW, entropic optimistic gradient update) separately on six rates; select strongest fixed recipe. Freeze development choices before scoring test. EG alternates prediction and correction; even depths measure corrected base. OMW uses one paired payoff evaluation per update. General-sum dynamics do not have a general convergence guarantee. Include randomized alternative route sham with equal number of learned inference calls but changed route and downstream state; it is uncalibrated and not causal evidence.

All solver arms use 2*T matrix-vector products at budget T=16/32/64; fixed arms need no model forward. Quantize normalized strategies with largest remainder to denominator one million; products/sums are exact safe JS integers for payoff range D=100. Regret of returned profile rechecked with BigInt; quantization is part of implemented solver. Each readout uses two extra products in numeric verifier and two in independent BigInt cross-check; successful kite recheck adds another two. Teacher and calibration products logged separately. Not a matched wall-clock, memory or FLOP claim. Fixed baselines are not charged fake model computation. Report router calls, exact profiles and history. No best-so-far selection. Native BPD trainer uses differentiable trajectory targets; hard best-response and argmax break gradient flow, so native integration requires explicit surrogate and hard-rollout verification.

Primary continuous endpoint: mean paired reduction in exact max regret at depth 32 against full and strongest fixed recipe selected on dev (uniform if full chosen). Minimum meaningful improvement .01 (one payoff percentage point). Two comparisons; report wins/losses/ties, mean, SD, conservative one-sided Hoeffding lower under independent roots and Bonferroni. At n=120 conservative half-width ~.248; power gate not expected to confirm .01. No sham calibration, causal claim, significance fishing, independent model roots for generalization, or claim of implementing MaximinKiteNE. Other depths, OMW, EG, sham and withheld family are descriptive.
