# NEC-03M: Source-only five-input native/TopK16 feasibility pilot

**Preregistered November 21, 2026, before any new five-input native model or SAE weights were trained.** This is a fresh-grammar **source-training-only** competence and feature-availability experiment on four roots of the newly registered NEC-03L population. It does not open any of the five-input development-evaluation groups, new embargoed roots, original four-input reserved contexts or the existing 64 confirmation worlds.

## New immutable source family

[NEC-03L's registered five-input source family](NEC03L_REGISTRATION_RESULTS.md) has 96 prospective development worlds and 32 embargoed roots. This first source-only NEC-03M pilot admits **exactly dev5-000, dev5-001, dev5-002 and dev5-003**, each with a different five-essential-variable Boolean function, focal-position quintet and fresh initialization seed.

Each source world partitions the full 4096-bit-history input closure into **80 training context groups ×32 focal masks**, 24 development-evaluation groups ×32 masks, and 24 reserved groups ×32 masks. This pilot trains and evaluates only the original 80 training-source groups. No endpoint from a 24-group development-evaluation or reserved split is computed, even in engineering smoke.

## Native model and independent additive teacher

Each of the four source worlds has a preassigned 900-step compact recurrent training schedule based on the existing PEF-07 Looper: 32 hidden coordinates, 12 tied chronological visits, 64-dimensional GELU MLP activation, AdamW LR .003, weight decay zero, batch128, gradient clipping norm1. Each world trains a *composed Boolean* head and a separately initialized, class-frequency-matched *additive-control* head (seed offset 100000). Both use only the 2560 parameter-training input histories and their respective target function labels, with a deterministic seed-specific sampling generator.

Every initial/final checkpoint weight digest and checkpoint byte SHA256 is archived. Measure clean native classification accuracy **in sample on the 80 parameter-training context groups**, with an engineering competency threshold 90%. This is not a generalization estimate. All failed learners remain in the denominator, with no per-world change in optimizer steps.

## Full 32-state source-native attribution

Previous NEC-03G source discovery used sixteen focal states per context. This experiment replaces the grouping with one **complete 32-state focal counterfactual block** for each of the first 40 source-training context groups.

Compute top-two memory-token GELU activation×gradient contributions at each recurrent visit against the model's clean predicted-class margin, without using true labels to select candidate sites. Build source-context-level Pearson-phi co-attribution graph, exclude ≥90%-frequency hubs, and choose the highest-ranked seeded-Louvain community with ≤8 occurrences per visit and total size ≤12. When the graph yields no qualified community, select exactly two frequent non-hub native GELU channels at each of the **third and fourth chronological focal positions**, source top-two attribution frequency at least 2/40. If fewer than four eligible channels exist, record no candidate and stop that arm's SAE/angle fitting.

Freeze the source roster/checkpoint hash before any new feature fitting or label-blind angle calibration.

## Source-only learned SAE and ranking

For each arm with a qualified source candidate, fit a **128-feature, TopK=16** decoder to the 64-dimensional GELU activations from exactly **40 complete source-training context groups ×32 focal histories**, using the fixed 480-step AdamW 1e-3 procedure and physically meaningful normalization. Source-trained means and variances, normalized reconstruction MSE, exact sixteen-code activity fraction, SAE weight/state byte digest and model identity are archived. The engineering SAE reconstruction floor is normalized MSE **≤0.03**.

A disjoint **other 40 source-training context groups ×32 histories** determine the SAE feature attribution rank for all twelve recurrent visits. This preserves the old physical decoder projection and clean-predicted margin direction method while changing the number and size of context groups. Every rank must be a permutation of all 128 source features, and the byte-state and source-score SHA256 identities are frozen.

## Source-only angular control availability

On just the first **8 source-training groups** (256 related input histories) per arm, compute the clean-chosen predicted-class margin gradient in the **32-D post-MLP-down coordinates of the hubs-only lesioned trajectory** at each source-selected recurrent visit. The original NEC-03K exhaustive angle-null algorithm chooses the same number of disjoint currently active TopK codes as the source donor among all admissible subsets, with no task labels used in routing. Match direct MLP-down output L2 dose by attenuation only.

The precommitted null feasibility floor is **≥80%** input/visit absolute cosine gap ≤0.25, ≥80% sites with positive physical dose, ≥99% dose matching within 1% and median source donor dose retained ≥25%. For this native/SAE source pilot, the combined source-model feasibility gate requires source-train clean accuracy ≥90%, source-native site found, SAE reconstruction MSE ≤0.03, and angle+physical signal feasibility. Each arm and full root reports every failure separately.

All active code IDs, candidate subset counts, 32-D feature physical output vectors and clean-chosen hubs gradients are archived so an independent pure-stdlib auditor can re-enumerate the source-only angle search. A second independent CPU auditor reloads each native checkpoint, recomputes exact source labels and all 2560 *in-sample* predictions, source-only SAE reconstruction loss and the other 40 groups' learned feature-rank digest. Every source byte checksum and protected cohort commitment is checked.

## Power and stopping boundary

This four-root effort is a source-only *engineering feasibility* preflight. Its result can tell us whether the new five-input task family is learnable by these compact 900-step PEF loops and whether source-trained TopK16 plus direction-matched controls have usable physical signal. It cannot justify any causal or independent-world statistical claim. The earlier source-ranked-vs-direction-matched four-input posthoc world-mean correctness gain **+0.16276pp** is below the frozen scientific **+2pp** minimum.

No new five-input development-evaluation group, within-world reserved group, 32 embargoed root or original 64 confirmation roots may be opened by this pilot. A future locked pilot must separately register a correctness endpoint and matched-sham family before any of those previously unexamined evaluation inputs are scored. **FSI-01 remains REDESIGN_OR_PILOT_ONLY.**
