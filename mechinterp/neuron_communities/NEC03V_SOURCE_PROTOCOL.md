**Prospective source-only registration, 22 November 2026, before new source scoring.** NEC03Q/R/S/T source feature experiments and the archived NEC03U margins all remain independently recorded. Earlier original-n source-ranked SAE code ablation gave +0.048828pp eight-root correctness and heterogeneous raw margins, below +2pp meaningful effect. This design tests whether a *decoder-coherent group of active SAE features* carries functionally necessary information when the complete full-affine reconstruction remains as background.

For each complete training-source group, save the unmodified native model clean-chosen logit orientation. ## Coherent group selection

At a selected visit, original 128-source-feature rank order and learned decoder columns are frozen. For each input, take exactly the 16 strictly positive active codes and project all physical decoder feature columns, **masked to the original native nonhub channels**, by the native mlp-down 32D weight. Define each feature-column cosine to another in this physical 32D space.

The **primary source quartet** is selected as follows: take the highest originally source-ranked active feature as a fixed seed. Add the **three** other active features with the greatest signed cosine to that seed's physical 32D decoder direction; break ties by original source rank and then integer feature ID. This is a decoder-coherent group, constructed before teacher truth labels are read. Group *cohesion* is the arithmetic mean of the six pairwise physical 32D cosines of its four projected decoder columns.

For each primary quartet, enumerate every **four-code subset of the remaining twelve disjoint positive active codes**, in lexicographic order. This gives exactly **495** possible disjoint controls per supported input/site. For a candidate, calculate its own mean pairwise physical decoder cosine (cohesion) and its **total physical 32D removal-direction cosine** to the full-affine clean-chosen gradient, weighted by the actual sparse code activations. Choose the disjoint control minimizing this **frozen scalar joint objective**:

\[
J=|\cos(d_{\mathrm{sham}},g)-\cos(d_{\mathrm{source}},g)|
  +0.5|\mathrm{cohesion}_{\mathrm{sham}}-\mathrm{cohesion}_{\mathrm{source}}|.
\]

The first lexicographic minimizer wins ties. The selected sham is admitted only if its **absolute gradient-cosine gap ≤0.25**, its **absolute group-cohesion gap ≤0.50**, the full-affine margin gradient norm >1e−7, and both original 32D removal vectors have a positive physical dose. Every candidate count, source seed, source/sham IDs, physical cohesion, direction gaps and objective score is saved. Sham source and coherence selection never read task truth labels.

The **secondary six-feature group** uses the same seed and the five physically closest projected active features, with an independently exhaustively selected six-code disjoint sham among the other ten features (**210** candidates). It retains identical pre-outcome group/dose rules, but is excluded from the single primary comparison. A third descriptive original-quartet control uses a fixed SHA256 index into the 495 disjoint candidate quartets based only on the world SHA, native teacher arm, source group, focal mask and recurrent visit, with salt NEC03V/source-only-coherent-quartet-hash-sham/v1.

## Equal physical removal dose and failure policy

For each group source and disjoint sham, compute the sum of decoder code contributions in native nonhub-masked **64D GELU** coordinates. Measure its direct **32D mlp-down output L2**. Attenuate both removal vectors to the **smaller** of the original two physical doses using gains between 0 and 1, never amplification. Physical dose equality must be within **1%**; the shared dose must be strictly above **1e−6**. Subtract the matched removal from the *identical* full-affine nonhub background. The original source graph hubs remain live and all 12 recurrent visits propagate the intervention nonlinearly.

If any recurrent site in an original input has fewer than exactly 16 positive active codes, weak full-affine gradient, missing source/sham, excessive angle/cohesion gap or inadequate positive physical dose match, set **both** source and sham removal vectors to zero **at every source-selected visit** of that input. Both trajectories remain identical full-affine restored. Retain the invalid input in the original 256-case denominator with zero signed causal contrast. The hash control has separate same-output-L2 dose/failure masks. Unavailable native source sites retain clean predictions and zero active-sham availability without removing that arm or root.

## One primary root-level effect and resolution gate

For each original paired-source-eligible world root, define S as the number of correctly classified original training-source histories **after coherent quartet removal**, and H as the correctly classified histories **after equal-output-dose disjoint physically cohesive sham removal**. The one and only primary source-group necessity effect is positive when the coherent source quartet is more necessary:

\[
D_r = ((H_{comp}-S_{comp})-(H_{add}-S_{add}))/256.
\]

Set original root3/root5 contributions to zero and average all eight registered world roots equally. A scientifically meaningful **+2.00 percentage-point absolute correctness effect** and exactly **one primary family** are registered before scoring. The historical exact two-sided root sign-flip p is **exploratory only**, conditional on independent-root sign symmetry; repeated training-source masks are never independent observations.

Define a separate **developmental resolution criterion**: the eight-root primary macro must exceed **+0.02**, at least **five of six originally source-eligible world roots** must have positive source-specific root effects, and every eligible composed/additive native arm must have at least **205/256 (~80%) available primary physically matched inputs**. All three conditions are required for the source-level mechanism-resolution gate. Even passing this gate cannot establish a population effect or enable 59-root causal scale-out without a new preregistered independent-root power analysis.

Secondary raw teacher-signed margin changes are normalized **within each frozen teacher model** by the larger of 1 or the **median absolute full-affine teacher-signed margin over all its original 256 training-source inputs**. This calibration rule is fixed before scoring, with all labels consulted after feature/sham selection. Report root and arm mean normalized sham-minus-source margin only as a secondary engineering diagnostic, never a substitute for failed primary correctness. The original six-code group, hash-selected group and full16 clean reconstruction comparisons are likewise secondary.
