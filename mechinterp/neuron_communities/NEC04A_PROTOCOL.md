## Exact grammar and source-context ownership

Each Boolean model world consumes **twelve binary history bits**, partitioned into **five focal positions** and **seven context positions**. Focal positions are unique 5-of-12 sets selected by a SHA256-ranked list of 792 layouts. The allowed AST operators are VAR, NOT, XOR, AND and conditional MUX. All programs are generated by a byte-defined SHA256 counter-based deterministic RNG, independent of Python global random state and future model outcomes.

A balanced anchor branch contains five-focal XOR parity with two context XORs. One outer context MUX combines this branch with a second deterministic seeded expression using the same fixed gate alphabet. Difficulty tiers have exactly **11 gates for easy, 15 for medium and 19 for hard**, with maximum respective AST depths **8, 12 and 16**. These gates are a **structural complexity proxy**, not a claim about future model accuracy.

The first of at most **64 deterministic candidate programs per calibration root** is accepted if its complete 4096-history Boolean truth table has 30–70% positive labels, all five focal bits are globally essential, at least three context bits are essential, and at least 64 of 128 context-specific complete focal truth tables have 8–24 positives out of 32. Candidates failing these model-independent constraints are rejected; exhausting the fixed candidate budget fails the corpus. All original calibration root program SHA256 identities and full truth table SHA256 fingerprints must be unique, without post hoc rerolling.

Each calibration root allocates all 128 contexts by a fixed SHA256 order into **80 source-training context groups, 24 development-context groups and 24 reserved-context groups**, preserving all 32 focal masks in a single owned context block. **Only the source-training contexts are labeled and materialized in NEC04A.** The result has 24 calibration roots ×80 source groups ×32 focal masks = **61,440 source-training rows**, each preserving the root ID, 12-bit history, context-group number, focal mask, difficulty tier and exact Boolean label. Development and reserved contexts remain unscored.

## Independent oracle and complexity receipts

The generator computes its 4096-case teacher truth table by bit-parallel Python integer Boolean logic, whereas the independent auditor uses a separate recursive **scalar Boolean interpreter** on every 12-bit history. It verifies the exact 512-byte truth-table SHA256 for each calibration world, every one of the 61,440 training-source labels, each complete context's 32 focal masks, and original context partition disjointness. The auditor also checks source-program SHA, fixed gate counts, input essentiality, class balance, root uniqueness, and full-matrix source evidence hashes.

The manifest preserves model-independent statistics: positive class frequency, Boolean algebraic-normal-form degree, essential input count and the number of balanced context-specific focal truth tables. Such symbolic complexity diagnostics do **not** measure clean or full-affine native model accuracy. No native-model training, sparse autoencoder fitting, task headroom screening, feature-group selection, causal sham inference or statistical significance test occurs in this generator stage.
