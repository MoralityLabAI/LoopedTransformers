# NEC-03V-B: separately registered SOURCE-ONLY coherent-group necessity pilot

**Status:** preregistered DEVELOPMENT pilot only. FSI-01 remains REDESIGN_OR_PILOT_ONLY.
**Parent:** NEC-03V immutable source-geometry PR #283.
**Old endpoint:** original NEC03T n-code necessity test retired after the NEC03U eight-root archive audit; all original artifacts preserved.

## Scientific question

For the original source-trained recurrent teacher, is removal of the strongest connected four-code *coactive SAE feature group* more damaging than removal of an equally sized **disjoint, physically matched active-code sham** at the same native masked 32D output norm? Is any effect stronger in composed than in additive teacher worlds?

The source-only test measures model behavior. Its previously audited source-fit geometry is NOT evidence of necessity. This experiment uses the original eight historical source worlds only. It is developmental, with no inference on the 69 recruited eligible worlds, reserved groups, 32 five-input embargoed roots or 64 old four-input confirmations.

## Fixed prior and source input identity

NEC03V_BEHAVIOR_SOURCE_PANEL_LOCK.json freezes all eight prior source artifacts, their individual original source-fit manifests and selected physical-roster SHAs. Each must match:
- Original native reset1800 model and source-fit TopK SAE checkpoint byte identities, original 128x32 source-masked decoder column audit, original original-source-only positive activation audit;
- Original source training groups 24..31, each with 32 five-bit focal masks in the same world generator order. All 256 cases per model arm remain in the denominator.
- Previously selected coherent group G of four positive active TopK codes, strongest connected by source-fit Jaccard + projected decoder cosine, and disjoint four-code sham H selected by closest source-only structural coherence then projected norm.
- Registered 32D physical removal vectors with nonamplifying min-norm common dose and a one-percent matched-L2 tolerance. Invalid-case pairs use ZERO removal for both sides at every registered visit.
- Original eight-world ITT fixed zeros at roots 3 and 5, even though raw behaviors can be reported.

The physical preflight is fixed **before behavioral scoring**. Eligible world arms require >=95% case coverage, at least 0.1 shared physical 32D dose, >=80% of selected paired site vectors with cosine <=0.95 (directional separation), and <=1% norm mismatch. These gates are source-only engineering thresholds chosen from prior label-blind physical feasibility. They are not p-values or a behavioral null distribution.

## Physical intervention and native transport

Use full-affine SAE nonhub donor B, preserving native original hub gates and decoder mean plus decoder bias. At each originally selected visit v, for frozen positive activations z_i and SAE decoder vectors W_i, construct the nonhub 64D group g and sham h:
  g = nonhub_mask * SAE_scale * sum(z_i * W_i, i in G).
  h = nonhub_mask * SAE_scale * sum(z_i * W_i, i in H).
Let d=min(||W_down g||_2,||W_down h||_2), and let source and sham gain be d divided by each raw projected norm, capped at 1. Apply donor B - lambda * gain * g or B - lambda * gain * h. Both 64D removals must project to the independently archived source/sham 32D vectors within 2e-4 absolute and 2e-5 relative per coordinate.

Preserve full 12-pass tied recurrence. The unchanged original source-hub gate is applied at each selected visit. Source/sham candidate IDs, physical doses, matching gains, input cases and recurrence sites are sealed prior to looking at any new behavior.

Registered lambda=0 full-affine baseline and paired group/sham dose levels lambda=0.25,0.5,1.0. The zero-dose route must agree with the original NEC03T source full-affine logits within absolute 1e-3, relative 2e-5, with the original exact class predictions unchanged.

## Endpoint and root-level analysis

The single developmental primary is:
  D_r = [(correct_composed_sham_lambda1 - correct_composed_group_lambda1)
         -(correct_additive_sham_lambda1 - correct_additive_group_lambda1)] / 256.

The eight-root mean averages 8 ROOT units equally. For original source-ineligible roots 3 and 5, D_r is forced to exactly zero in the registered intention-to-treat estimand. Report the corresponding raw arm differences as separate diagnostics.

The effect floor for *research promotion consideration* is +0.02 (two percentage points), inherited before source-only scoring. With root count eight, also report all root signs, leave-one-root-out effects, the largest root's share of any positive result and whether the physical controls actually move behavior; do not derive a population p-value or equivalence claim. Because these are historical training-source roots, observed effects are exploratory relative to any fresh population.

Secondary descriptive outcomes only: each registered intermediate dose's correctness count relative to full-affine, per-arm source/sham correctness gaps and raw signed-margin diagnostics WITHIN a teacher. No cross-model raw signed-margin calibration or new significance claim is permitted from the posthoc NEC03U margin audit.

## Frozen method and independent replay

First commit scorer, independent replay, this protocol and synthetic-only tests. Freeze Git blob hashes of the scorer, independent auditor, source-cohort loader, native Looper, original source attest, original geometry and the 12-pass transport implementation in NEC03V_BEHAVIOR_METHOD_LOCK.json in a distinct pre-scoring commit.

Then a validation-only job checks those SHA pins, original source artifact hashes, selected four-code physical roster and physical gates, WITHOUT calling a model.

Only then execute the registered CPU-only source scorer. It must:
- Refuse all root IDs outside original 0..7, require an explicit execute-registered-source-scoring CLI switch and reject changed SHA, roster, source membership or model checkpoint identities.
- Recompute source teacher labels on exactly the already recorded 256 source cases for each original model arm, checking them against the old NEC03T case labels. Labels cannot participate in source-group selection.
- Save unabridged 32-case arrays of logits per mode for each group and arm, record native forward calls and unchanged native/SAE weights.
- Fail if a source-ineligible mask changes behavior, if a zero-dose baseline differs from NEC03T, if an unmatched 32D removal is applied or any full source mask is omitted.

The independent auditor uses a *separately implemented* MLP-down hook and donor construction, executes all original 12 visits, checks every saved group/sham logit, recomputes source labels, rejects altered physical/gain receipts, validates old full-affine baselines and recounts the full root's primary numerator. Synthetic tests must also reject altered roots, physical sham vectors, candidate coverage and mismatched weights. The source pilot can only be considered independently audited after all eight root audits pass.
