## Fixed label-blind selection algorithm

Within each original root, model arm and previously registered source visit:

1. Reevaluate support of EVERY up-to-twelve frozen source-discovery quartet, counting original 256 source-calibration cases where all sixteen TopK codes are positive and the quartet is active. Require at least **64 cases**. Invalid cases remain in full 256 denominator.
2. Rank eligible quartet candidates by highest calibration positive support, then smallest frozen source-discovery candidate index. Test ONLY the highest-ranked candidate at that original recurrent source visit.
3. Run three registered unordered 2+2 partitions of the selected quartet against a physically matched, disjoint active four-code sham with fixed 96 deterministic SHA control proposals. Use **32 mechanical cases**, chosen without outcomes: masks [0,8,16,24] in each of the eight calibration context groups16..23.
4. Count cases with nonamplifying matched source/sham four-code physical 32D dose, original pair norm ratios and pair internal-angle constraints. Match successful exact 32D vectors independently. Rank partitions by number of physically feasible cases, then ascending partition index. Any zero-feasibility site retains a physical-zero receipt; the site can remain unselected.
5. Across the original selected sites, select ONE source site per model arm, ranking first by matched mechanical 32-case count, then by total 256-case quartet support, then ascending original recurrent visit and frozen candidate/partition indices.

The output retains support counts for the entire original candidate menu and every tested pair partition, plus the original source-pack, calibration-coefficient and independent replay SHA256 identities. The chosen shortlist is physically testable and has never been selected by functional/behavioral outcome. It is not evidence of necessity.

The independent implementation recomputes all 256-case menu support counts, independently audits the source discovery roster and each admitted 32D pair's physical vectors, verifies the fixed mechanical sample, and recomputes exactly the chosen candidate/partition/site priority. Because both implementations use the same deterministic disjoint-sham search to reproduce candidate IDs, this is a **partial independent geometry audit** and source-custody replay, not yet an independent native behavioral test.
