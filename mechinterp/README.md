# mechinterp

Mechanistic-interpretability work on looped (weight-tied, recurrent-depth) transformers.

| folder | what it is |
|---|---|
| [deuterium/](deuterium/) | Deuterium retrospective: verified recovered TRM/VPD archive, 16-versus-12 graft audit, frozen steering results and Actions-based engineering replay |
| [loopscope01/](loopscope01/) | LOOPSCOPE-01: a fragility-vs-specificity instrument (TCA) for looped models, and a preregistered series (Q1–Q11) asking which loop-level statistics predict length extrapolation in toy loopers |
| [loopscope02/](loopscope02/) | LOOPSCOPE-02: recurrent Sudoku/TRM and looped LM causal and fiber controls |
| [loopscope03/](loopscope03/) | LOOPSCOPE-03: three-ledger recurrent-state tests, conditional refill and path independence |
| [phase_gauge07/](phase_gauge07/) | Native phase/gauge observer controls and source-locked cyclic telemetry |
| [sae_causal_transfer/](sae_causal_transfer/) | LS-SAE01: source-indexed SMC-13–17 causal SAE transfer, 96-feature inactive-displacement controls, numerical encoder observer, exact loop-depth witness and unit-tested model adapter |

Related, elsewhere in the repo: `papers/rmp_looped_mechinterp/` (paper) and `reports/technical_note_looped_mechinterp.md`.

The LS-SAE01 observer is executable on frozen physical SAE dictionaries; its independent source-indexed SMC-17 result passed **1/4** registered receiving-SAE comparisons under the stronger all-inactive-feature-matched sham. The local exact-rational recurrence example is a synthetic mathematical witness, pending any separate trained LoopedTransformers checkpoint evaluation.
