51st persisted neural reply (WinError 5/PermissionError). Fifty successful
official SDK episodes bind to distinct neural replies; one neural reply is
unbound. All 51 prefixes and 2040 physical vectors pass the original strict
native audit. The remaining 238 official grades stay missing. No NF4 response
is replayed, no wrong answer is retried, and the frozen source/receipt remains.

the neural server was verified absent. Unknown original process exit codes
remain null. The source/backend/taskset/scoring/model files are unchanged.

the existing authenticated health endpoint instead of opening live progress
JSON. Strict original audits operate on immutable snapshots: hardlinks of
closed neural records/state files, terminal receipts when present, and only
complete SDK JSONL lines. Offline progress counts derive from authenticated
health/terminal receipts and are explicitly marked as snapshots. No model
response is manufactured or replayed. Final closed-file hashes bind the same
original artifacts; partial snapshots identify only a closed prefix of traces.

delete-sharing reader also fails on this host. The proposed health-only path
passes 100 concurrent worker-style atomic writes and 100 RPC reads without
any live progress-file reads or write errors. The failed sharing fixtures
remain local. The final passing receipt and exact supervisor source hash are
registered before BF16 model inference.

SIGTERM, record actual observed exit/coverage, and preserve the trace prefix.

model while an existing worker is alive. Normal finite budgets, one numerical
CPU thread, Below Normal priority and all original input/score/vector checks
remain. The user's separate math process is untouched.

This is an operational amendment, not a new competence test, a changed model
condition, a repaired NF4 attempt, or another PRIME06 tail. All outcomes are
exposed development data; formal comparisons=0 and donor transfer is disabled.
The original 168-case test stays sealed. Only aggregate reports and hashes
are published; all traces, state vectors and per-record derivatives stay local.
