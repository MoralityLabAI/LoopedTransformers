## Intervention and native measurements

Start from a clean **ACT1** \`(z_H,z_L,x_emb)\` anchor for each source puzzle, using the original pretrained network. For every frozen eligible arm, inject one source board-token \`z_H\` unit direction with physical L2 dose **±0.20, ±2.00, ±8.00**, with no change to any other token, \`z_L\`, embedding or weights. Run the clean and all signed variants **together in one native forward batch**, sampling full **97×512 z_H and z_L** and full **81×9 logits** at ACT3, ACT6, ACT12.

For every puzzle, arm, dose, sign and horizon, report:
- Input-relative transport \`G_H=||z_H^edited-z_H^clean||_F / radius\` and \`G_L\`, original source token norm, edited site and other 96-token displacement, blank/given board displacement, and ACT3→ACT6→ACT12 signed attenuation.
- Centered 9-digit head \`W_c=(I-11^T/9)W_digits\`, orthonormal rowspace via SVD with rank cutoff \`1e-7*sigma_max\`. Report \`||P_W delta z_H_board||_F\`, its orthogonal complement, rowspace displacement fraction, and same-run exact centered logit reconstruction error. Tolerance is **2e-4 Frobenius**; any same-run algebraic failure stops the run (can be interpreted as an instrumentation/numerical failure).
- For every **originally blank** cell, clean argmax digit and winner-to-runner-up clean margin. Define the sufficient finite **margin certificate** \`m_min > 2*epsilon\` where \`m_min\` is the smallest clean blank winning margin and \`epsilon\` the maximum absolute 81×9 edited-versus-clean logit displacement for that same signed edit, at the *same horizon*. Also record exact per-cell strict winner-versus-all-rivals inequalities and actual flip counts; a noncertified puzzle may still have zero flips. Zero-margin ties fail strict certificates. Separately record saved original-logit drift **only for the 16 reference puzzles** without any replay-tolerance acceptance criterion.
- Full actual 81×9 signed logits and original source/target, per-horizon blank-cell correctness, wrong→correct repairs, correct→wrong corruptions, original-given disagreements, exact 27-unit solved boards, all signed direction geometry, and source-only difficulty. Report ACT3→ACT6 and ACT6→ACT12 error recovery without retrospective sign selection.

The original all-81 logit score and exact sudoku verification are computed on **the same native forward tensors** as the transport. Archive comparison is a separate diagnostic and cannot invalidate the within-forward causal comparison. No historical per-logit \`0.0002\` or A1 \`0.001\` cross-run threshold is reused as a scientific gate.

## Preregistered hard-cohort accuracy endpoint

For each external full puzzle at ACT6 and physical dose 8.00, compute the **sign-symmetrized correctness gain** for donor STATE_POWER and donor RANDOM, \`C=0.5[(blank_correct(+)-blank_correct(clean))+(blank_correct(-)-blank_correct(clean))]\`, then paired \`D=C_donor_state-C_donor_random\`. Use both fixed 8-puzzle families with **all eight cases in the denominator**, including ineligible donor-state vectors (\`C=0\`), and report clean-inexact count.

A full family passes only if **at least four** original clean ACT6 puzzles are inexact, **at least six of eight** puzzles have \`D>=1\`, and the strictly positive lower 95% puzzle-cluster percentile bound from **2000 paired bootstrap resamples** (seed \`202611170+len(family)\`, sorted indices 50 and 1949) is observed. Both families must pass for overall success. This is deliberately demanding because an arbitrary transferred direction is unlikely to improve verified accuracy. Output-flip advantage, paired net repair, delayed ACT12 recovery and SAE/LOGIT_POWER comparisons are **secondary**, with signed dose curves reported regardless of success. Reference-cohort transport has descriptive mechanism bins \`G_H<0.1\` (contracted) and \`G_H>=1\` with zero flips (persistent output-silent), and no new primary gate.

## Independent audit and execution

A source-only unit+admission job must run first, before any new hard-cohort native inference; preserve all 20 source/target proof receipts and exact puzzle uniqueness, provenance hashes and propagation checks. Run original 16 reference transport and separate four-hard-puzzle engineering pilot, then 16 external hard sources only after both audits pass. Model stage must write all output JSON before independent standard-library auditor consumes it. Auditor recomputes registered source identity, saved logits, integer Sudoku correctness, each strict margin certificate, paired score, bootstrap and Pythagorean norm and singular bound checks. It cannot reconstruct 97×512 hidden states or rerun the pretrained model; this limitation is mandatory in final result.

Pilot is excluded from scientific gate. No threshold amendment after full data is generated, and failed stages or source admissions remain permanent public evidence.
