# LOOPSCOPE-06 / LGA-03: A learned horizon-conditioned potential for recurrent dynamics

**Prospective registration, November 18, 2026, before any LGA-03 value-function fitting, fresh test generation, or scoring.** The completed LGA-01 study found 3/3 trained 44K tied TRM seeds with positive current-head gradient alignment; LGA-02 found only 1/3 seeds with positive terminal four-pass loss gradient alignment. The hypothesis here is that an auxiliary *learned horizon-conditioned scalar value function*, trained on separate calibration trajectories, recovers more of the true terminal-loss gradient than local-head or matched untrained-value controls.

## Interpretation

Passing would demonstrate that an EXTERNAL calibration-trained horizon-conditioned value model captures terminal-loss directions on unseen recurrent states. The original TRM is not trained on this value network and cannot be claimed to implement its gradient. SAE dictionary projections and terminal head-null gradients likewise do not establish intrinsic semantic coordinates. Earlier LGA-01 POSITIVE, LGA-02 FAIL and SMC-27 FAIL conclusions are unaffected.
