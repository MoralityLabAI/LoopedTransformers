# DEUTERIUM-NATIVE-01: recurrent-weight VPD steering on the frozen four-pass TRM

**First source-only registration: 19 November 2026.** This protocol is committed separately, before creating new calibration/heldout examples, running VPD optimization on this target, or checking intervention outcomes. Subsequent code commits must preserve this registration; any design change requires a visibly versioned amendment and a fresh, unused test seed. The initial release will be **development-only** because all three pretrained teacher roots have appeared in previous LOOPSCOPE studies.

## Hypothesis and prior evidence

Test whether a *learned VPD rank-one weight direction* improves original native four-pass cyclic-copy task loss more than an equally searched random outer-product direction, when the **same recurrent parameter matrix is edited at all four weight-tied applications**. Unlike DEUTERIUM-FOLLOWUP-01's synthetic output-head study, this experiment edits the trained recurrent block `block.chan_mix.2.weight` (shape 48 × 128), which changes subsequent hidden-state dynamics. The old three-seed Deuterium result was `NO_REGISTERED_ADVANTAGE`; it cannot count as a positive prior. LOOPSCOPE-08's shared external energy has trajectory-alignment evidence, while its physical energy-gradient steering failed to show task-CE superiority over random. LOOPSCOPE-09 to LOOPSCOPE-13 analyzed state-space donor/gradient/curvature interventions with these same pretrained teachers. This study tests a different *parameter-space* intervention and must not present repeated teacher roots as independent out-of-family confirmation.

## Target, VPD implementation and matched search

Frozen recurrent parameter target: `block.chan_mix.2.weight` of each independently trained teacher (shape 48 × 128). On all four passes the same exact patch is in force. A per-pass-only patch is an EXPLORATORY depth-local diagnostic and must be explicitly distinguished from the primary shared-weight patch. Do not edit the head, token embeddings or positional embeddings.

Use original `MoralityLabAI/param-decomp` implementation at commit `2df0092d5be4d8e4748b3c66ef8325dedef17549`: the stock `optimize` path with `PGDReconLoss`, `ImportanceMinimalityLoss`, and `FaithfulnessLoss`. Adapt the module pattern to `block.chan_mix.2` and verify exact internal checkpoint keys/rank-one component mapping before fitting (any incompatible target API blocks the study). Freeze 16 learned components, source training batch size 8, 32 faithfulness warmup steps and 64 main steps, constant AdamW LR 0.001, PGD 2 mask steps, model/output KL reconstruction, float32 CPU; use the original implementation's actual final-index step semantics. Keep a complete configuration and optimizer loss/faithfulness trace. VPD optimizer sees original training inputs only. Report fit time, peak memory, components-only final-model fidelity and **residual-restored four-pass** logit fidelity independently. Reconstruction by restoring the residual must reproduce clean final logits within max abs error 1e-4 on old source data; an apparent decomposition advantage without its residual/parameter fidelity is ineligible.

The 16 learned rank-one candidate weight matrices are the outer products of the decomposed factor pairs, individually normalized to `rho=0.01*||W_original||_F`. A SHA256-derived bank of exactly **16 random Gaussian outer-product** matrices is normalized to the same rho and receives precisely the same two-sign, 32-evaluation calibration search. Each arm selects the candidate/sign with minimum calibration mean GOAL-token NLL, tie-broken by smallest index then plus before minus. Both selectors use the same 731055 inputs and labels; candidate banks themselves use training-only learned weights or random generator and never the scored 731057 labels.

Add a **task-gradient rank-one oracle control** from the correct-label gradient of goal-token loss on the original train set 31041, its leading rank-one SVD outer product, negated, equal rho, with no test or calibration-based orientation changes. Report separately as label-supervised and more directly task-optimized than VPD's unsupervised components. Keep a zero-edit sham and unmodified clean model. The VPD bank and random bank both require 16 finite rank-one directions, verified conceptual rank=1. Check actual FP32 applied deltas, exact weight restoration after every calibration/heldout call, actual normalized Frobenius-dose relative error <=1e-4, and matching native four-pass forward and manual tied-block replay max abs error <=1e-4. All candidates/doses/scoring decisions must be persisted *before first heldout generation*.
