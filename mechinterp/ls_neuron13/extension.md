# Adaptive LS13 extension: multi-anchor code search
After observing the primary numerical bound outcomes (no exact certificate scoring yet), test whether fitting nonlinear scales to the initial corrupted codebook prevents useful discrete moves. Apply to ALL 12 seeds at 15% only. New single and paired arms restart from the original noisy initialization. Same 16 rounds and region objective. At each round profile all candidate codebooks at both the current fitted nonlinear scales and the original initialization scales, take the top four candidates per anchor (including no-op if ranked), refit all five continuous variables for each, and accept the best strict loss improvement over the previous state. Same move sets as primary. At each anchor, also evaluate current codebook and refit it to distinguish restart benefit from code edits. An additional continuous_restart arm uses only the current codebook with both anchors. All retained and rejected shortlisted fit summaries recorded; profile candidate counts and fit evaluations separately. No use of numerical rollout accuracy, exact certificates or template target codes for selection. This is adaptive development, with higher compute and no prospective gate; original primary unchanged. Same fixed 1/32 certificate and no post-verification repair.
