## Deterministic rebase

For every site, form `W_hat = (V @ U).T` from the frozen trained factors using float64 products. Compute its full thin SVD in float64 on CPU: `W_hat = A diag(s) B.T`. Define `V_new = B * sqrt(s)`, `U_new = sqrt(s) * A.T`, cast both to float32, pad zeros to 512 components if necessary. Factor values are frozen. This preserves the **trained reconstructed operator**, not the target weight matrix. To avoid an unwarranted basis-causality claim, the full 512-component residual-off original and rebased rollouts must agree per board at the relevant readout.

Record per-site `||W_hat_original - W_hat_rebased||_F / ||W_hat_original||_F` and require <= 1e-5. Record `||W_target-W_hat||_F/||W_target||_F`, normalized off-diagonal write Gram coherence, and activation-weighted residual/omitted-write RMS and cross term from the fixed training subset. These are descriptive and cannot change the registered decision.

## Precision, hypotheses, analysis

A readout is interpretable if **every** board has F0, F1 and F2 target KL <= 1e-5 and F4-vs-F3 KL <= 1e-5, and **every site** satisfies the 1e-5 relative full-operator rebase tolerance. Otherwise mark the readout invalid and withhold mechanistic decisions, retaining its raw measurements for diagnosis. Pass 20 is primary. Later passes are secondary only when floors close.

- **H1, primary spectral-rebase improvement:** `D_i = KL(R1)_i - KL(T1)_i`. Use 20,000 paired-board percentile bootstrap resamples (NumPy PCG64, seed 2026111803) independently by checkpoint. A two-checkpoint improvement claim requires the upper 97.5th percentile of the mean paired D to be < 0 for both checkpoints, plus the pass-20 validity controls. Reverse inequality for both indicates worsening; otherwise inconclusive.
- **H2, secondary recovered competitiveness:** `M_i = KL(R1)_i - KL(S2)_i - 0.10*KL(S0)_i`. Report upper 97.5th percentile paired bootstrap interval with the same resampling rule. A two-checkpoint non-inferiority description requires both upper bounds < 0 and valid controls. It never upgrades H1.
- **H3, diagnostic residual contribution:** report mean F3 target KL and `F3 - F1`, paired by board, and the clean-input reconstruction residual norm. A large residual is evidence for a missing-factor reconstruction floor, independent of H1.
- **H4, descriptive:** `R1 - T3` and `T3 - S2`. The trained CI is specific to the original coordinates; do not apply it to the rebased factors.

For each paired contrast report n, mean, median, percentile bootstrap 95% CI, wins/losses/ties, largest absolute board share, and effective effect count `(sum |D_i|)^2 / sum D_i^2`. Include board hashes, exact checkpoint/model/factor/CI hashes, and preregistration commit in the receipt. There is one deterministic factor rebase per checkpoint. Evaluation boards will be considered consumed after this run, even if the hypothesis fails.
