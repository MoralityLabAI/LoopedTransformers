## Exact semantics

A layered deterministic decision diagram stores (depth, unassigned-domain vector) as its state. At the next cut variable, allow exactly its current values, intersect every remaining neighbor with that value's original relation row, reject empty domains, and erase the assigned slot. All compatible label prefixes giving the same domain state merge; preserve labeled transitions rather than materializing paths. Each accepted path corresponds to one internally compatible cutset label with nonempty residual domains. The same residual graph is used for every terminal. Count labels by dynamic programming, not enumeration.

For each terminal signature d, partition the residual graph into actual connected components. Cache a compiled elimination tree and its calibrated marginal tables by (component identity, local residual masks); optional additional cache by exact local singleton evidence. A terminal can contribute any global support only if every one of its components is feasible under the same evidence. Never combine marginals from inconsistent terminal labels. If residual is empty, the conjunction is true. Under cutset evidence, forward-reach terminal states through allowed edges; under residual evidence, test local components, then mark the surviving terminals. Traverse backward, taking only edges with reachable source, permitted label and viable destination. The union of these edge labels gives exact cutset supports. Union the residual supports over viable terminals only. Reconstruct a witness by following one viable label path and gluing component witnesses at its terminal. This representation can still have exponentially many distinct terminal signatures; no generic polynomial complexity or completeness beyond caps.
