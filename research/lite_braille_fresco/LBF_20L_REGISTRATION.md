# LBF-20L registration: profile-aware cutset planning and prefix quotienting

Parent 63631635 (LBF-20K). Development-only standard-library CPU study. No new fits, sealed evaluation or general solver superiority claim. All exact answers checked independently.

## Objective and algorithm

For candidate cutset C, let P(C) be the product of original AC-domain sizes on C. For v in C, a value's profile is the vector of compatibility row masks intersected with the original domains of its remaining neighbors outside C. Let g_v be the number of distinct such profiles. Every complete compatible cutset assignment has a residual-domain signature determined by its tuple of profiles. Internal cutset constraints and empty-domain rejection can only reduce the number of signatures; hence G(C) <= product g_v <= P(C). This is an upper bound on signature count, not an estimate of exact satisfying assignments. Nominal bag cost W(C)=sum 4^|B| for the residual min-fill forest. Rank feasible plans by product(g_v)*W(C)+P(C)*(n+|C|); infeasible plans by excess maximum bag size then this proxy. Proxy is heuristic, not measured-time bound. A fast bitset min-fill implementation uses the original min-fill tie break.

Every planner respects maximum residual bag size6, raw branch product256 and 160 distinct width-plan evaluations. Degree-first and min-fill greedy are controls; both use the same fast width engine. Degree takes the highest remaining degree (domain then ID tie); min-fill ranks each one-vertex removal by maximum bag size, domain size, nominal slots, vertex ID. Profile greedy chooses best ranked removal until feasible. Profile beam width3 explores at most one layer beyond first feasible depth, returns best feasible candidate seen under cap. Cap can occur without proving no admissible plan exists. Hybrid runs beam and falls back to complete DFS-cover if capped. No answer depends on a score.

Prefix grouping: maintain residual domains for all unassigned variables (including future cutset vertices), and all compatible label prefixes. Extend by a permitted value, intersect each remaining neighbor's domain with its row, reject empty masks, set assigned slots to a common sentinel, merge equal domain states. Since future restrictions and internal-edge validity depend only on these domains, identical states have identical possible extensions. Retain original labels through all grouping; evidence on cutset labels is checked separately. Raw grouping control enumerates all assignments then restricts as in 20K. Both use the same residual Tree and 20K's exact conditioned support union. Profile grouping can also occur with no cutset. A contradiction detected by initial AC returns exact zero supports for every query.

Lean checks six abstract profile/quotient identities. Independent audit: 32 n4 + 24 n5 fresh cases, exhaustive assignments, every cutset of size0..3, compare fast order to original min-fill, raw vs prefix maps including every label, profile-count bound, and all four planners with forced maximum bag size3 against exhaustive singleton/joint supports and witnesses. Explicit cap checks. These audits do not mechanically prove Python refinement.
