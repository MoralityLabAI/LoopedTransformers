# LBF-20I registration: selective ternary persistence and exact separator controls

Parent ffb883ff (LBF-20H). Symbolic-only CPU development pilot; no new models, no sealed outcomes. No significance or solver-superiority claim. Exact finite audit and generated development comparisons are separate evidence classes.

## Operators

Represent each unary/pair scope as a packed Boolean assignment table (D=4). For a bag B, join all retained face relations lifted to B, then intersect each face with the projection of that same joint. Empty join refutes the instance. No global solution can be lost: its restriction is a witness in every projection. All triple bags over pair/unary faces to fixed point give pair-consistency closure. Promote ternary faces of selected four-variable bags, retain their joint restrictions, then run triple and selected quad joins to fixed point; compare projecting the same four-bag joins only to pair/unary tables. This isolates persistence of higher-order information from the larger local join itself. Full promotion uses every quadruple. This is bounded-width local consistency, not complete CSP solving. Stored logical bits are not measured memory. Bag revisions have unequal arities; report nominal D^arity slots, actual face lifts/projections and elapsed time.

Lean: projection inclusion, monotonicity, sound join projection, locality and two-bag separator gluing theorem. Conditional relational statements, not a general proof of the finite table code. Exact audit: 48 independent n4 generated systems, all 256 assignments each; compare both rank2/rank3 quadruple closure tables against independent synchronous tuple enumeration, replay feasible assignments in all retained scopes, exact width-capped elimination vs exhaustive SAT. K4/3-color and K5/4-color pair consistency unchanged; full four-bag closure refutes K4 but not K5, five-bag join refutes K5. Specialized exact min-fill Boolean variable elimination, maximum bag size 6, reconstruct a satisfying assignment from retained factors; width-cap fallback to bounded AC-LCV. On width<=cap, no arbitrary truncation. 

## Development comparison

48 n8 and 36 n12 cases, seeds 2026112561/62; equal counts in four generator strata: nonfunctional random mixed binary CSPs, random 3-color graphs (alternating planted/unrestricted), even/odd wheels with attachments, conditional odd wheels with a selector whose 0 mode restricts wheel colors to three and whose 1 mode permits four. Planted obstructions intentionally probe limits; shared template families, no canonical lineage or confirmatory claim. Exact unary feasibility from independent complete AC+DFS, not provided to controllers. Retain all roots. 

Ten arms: AC-LCV, singleton AC, DSATUR on pure coloring graphs (AC fallback elsewhere), VE6, pair closure, tight-selected four-bag joins with no ternary persistence, tight-selected with ternary persistence, uniformly shuffled selected with ternary persistence, min-fill priority with ternary persistence, full ternary closure. All selected arms allocate at most 2n quadruples after pair closure stalls with multiple candidate values. Tightness sums pair-density deficits in the post-pair-closure table; min-fill prioritizes elimination bags of size<=4 padded to containing tight quadruples, then fills the same budget with tight order. Selection uses no hidden labels. Uniform uses root hash. All retained triples get persistent relations, each join updates all available subscopes. Full arm uses all quadruples. Every arm then uses same 128-node capped AC-LCV unless specialized exact control solves/refutes. No learned pruning. VE and DSATUR use different work units; compare statuses and actual time, no misleading node equality. Pair/ternary filters intentionally pass unary projections only to common DFS (rather than treating pruned pairs as new input rules); this isolates projection benefit and can understate the value of higher-order relations. A complete global assignment is validated by the original CSP. Clear value-dependent lift/project caches per arm; static index partition tables may warm across cases, rotate arm order. Measure init, choice, closure, search and end-to-end; exact label time excluded.

Primary descriptive screen: paired additional impossible unary removals and contradiction detections over full pair closure on informative roots; compare tight persistent vs identical tight bag choices without persistence, then selected vs full. Report family-level outcomes (wheel vs conditional wheel vs random), all budgets actually used, timing, logical storage, nominal slots, and VE width caps. No further training unless a meaningful advantage over exact specialized controls survives.
