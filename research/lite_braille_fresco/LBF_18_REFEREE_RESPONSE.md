## 1. Blocking soundness correction
The referee counterexample is w=abc, reversible rules abc<->def, ab<->de, bf<->cc. Concrete reachability contains abc -> def -> abf -> acc. Inspection of LBF-17's symbolic_prov4_adj2 and FastProvenanceBigramCell confirms pass-index-1 suppression if the rewrite RHS agrees with the root substring and its position agrees modulo the fiber count. In the counterexample the suppressed de->ab rewrite leaves the final f changed. The concrete last-exit decomposition theorem is independent of this invalid local shortcut. The executable Lean stepPos1NonBacktrack is broader still, suppressing matching root substrings across later passes; its tests are not a universal refinement proof for the implemented transfer.

### Sufficient guarded transfer
For root w and provenance fiber f, let S_f be exact one-hop successors produced by redex origins p with p mod F=f. Let D_f be the union over x in S_f of coordinates i where x_i differs from w_i. Compute D_f once as an exact bit mask. At pass two only, suppress a rewrite on interval I with RHS w restricted to I if the legacy predicate holds AND D_f is a subset of I.

Proof: for every concrete x in S_f, x agrees with w outside D_f and hence outside I; the replacement writes w inside I, so the successor is exactly w. The initial root is retained in the identity fiber. Every nontrivial reachable endpoint has a shortest path without a revisit to w, so removing only these root-return transitions on pass two preserves bounded concrete reachability. With a sound abstract transfer at each other step, the guarded abstraction remains an overapproximation. This is a sufficient guard, not the most precise one. Modulo collisions can prevent some otherwise safe suppressions. The reference implementation concretizes adjacent bigram supports explicitly for small fixtures. This mathematical argument does not prove the floating-point implementation or the other local transfer operators sound.

[Boolean guard reference](lbf18_root_guard.py) and [regressions](tests/test_lbf18_root_guard.py) implement an independent exact-word and adjacent-bigram oracle. The legacy neural source and archived checkpoints remain unchanged. Next implement the same mask in the optimized symbolic and neural cells on a new versioned path; retain exact Boolean support separately from continuous brightness. Make the formal Lean transfer suppress only certified root returns; recheck finite-precision thresholds and longer horizons. Prove the actual abstract transfer sound rather than relying on a general abstract-interpretation theorem with an assumed sound transformer.
