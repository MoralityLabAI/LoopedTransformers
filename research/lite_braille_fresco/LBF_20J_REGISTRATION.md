## Exact decomposition and query semantics

Use LBF-20I's min-fill elimination order. Each bag consists of the eliminated variable plus its remaining neighbors. Connect it to the bag of its earliest-eliminated remaining neighbor; disconnected components are separate trees. Check running intersection and original-factor coverage. Maximum bag size 6; wider instances explicitly return width_cap. Compile unary/edge factors once. Upward messages are existential projections of joined local/child relations to edge separators; downward calibration intersects the child's upward table with the calibrated parent's separator projection. This remains exact even though the parent already includes the child's upward message: the repeated child condition is redundant. Inductively glue subtree witnesses across separators. A calibrated bag is the exact projection of global solutions, or all projections empty if any component is inconsistent. Querying all unary marginals requires only local projections.

For singleton evidence v=a, condition its home bag in the calibrated forest and propagate outward along each incident edge, intersecting the original neighboring calibrated table with the current separator projection. Stop if the neighbor's calibrated table is unchanged; this leaves all assignments on that side feasible under the evidence. Disconnected components remain unchanged when evidence is feasible. If evidence is infeasible, all supports are zero. This is exact by running intersection and separator gluing, not general loopy local consistency. Each pass visits at most O(n) bags; nominal logical work is exponential in the maximum bag size, not polynomial in arbitrary graph width. Logical packed bag bits exclude Python/cache memory and are not RSS.
