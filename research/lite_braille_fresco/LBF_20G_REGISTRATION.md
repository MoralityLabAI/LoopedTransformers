# LBF-20G registration: relation-valued recurrent composition

Parent b8f80bc7 (LBF-20F). Development CPU study. No sealed evaluations. Freeze design before execution.

## Mathematical target

R_{ij}^{t+1} = R_{ij}^t ∩ ∩_k (R_{ik}^t ∘ R_{kj}^t). Preserve every satisfying assignment and constrain every balanced route of height t (at most 2^t edges). Every walk of length 1..2^t can be split recursively and padded using keep. Hence an inconsistent permutation-cycle diagonal is excluded at sufficient depth. This does not imply general global consistency: the complete graph K5 with four available colors is unsatisfiable but unchanged by path consistency. Lean formalizes preservation, balanced-route containment, the capacity bound and cycle exclusion; executable refinement not claimed.

Audit: 96 new four-variable systems, all 256 assignments each, exact pair supports, no hard support losses through four synchronous rounds. 28 permutation rings (4 per n=6,8,12,16,24,32,64): compare diagonal projection to exact functional-component anchor propagation and singleton AC. Require ceil(log2 n) rounds. Functional anchor projection is exact on connected total bijective relations: a root value uniquely determines all values, reject on inconsistent cycles or domains. Disconnected components combine independently. This is the strong specialized control. It is not available for arbitrary relations. Measure actual times; triple counts are logical compositions, not measured FLOPs.

## Models

A cell receives the initial Boolean compatibility B, current scalar relation state S, and min/mean/max over intermediate variable k of the normalized shared-witness product ∑_u S_ik[a,u] S_kj[u,b]/4. Shared per-entry MLP 5→24→1, tanh. Soft update S=B sigmoid(logit); soft outputs may be wrong, never used to prune. soft1 vs soft4 share parameters; untied4 uses four distinct cells. hard3_readout uses three exact Boolean rounds followed by a single learned cell (four total composition passes, one learned block). Separate hard1/hard3/hard4 no-parameter baselines. Hard3 readout has access to exact structural support, but predictions themselves are not sound masks. This design tests a concrete scalar relation cell, not all higher-order neural architectures.

Train roots n=6: 96 new mixed CSPs and 24 color graphs. Root and up to four singleton-conditioned AC-surviving frames, exact *pair* supports by exhaustive 4^6 assignments per frame. Train only allowed input relation entries, BCE, 320 AdamW updates, batch8 lr .003 wd .0001, 3 seeds107/109/113, matched draws. All 12 fits archived by checkpoint hash. Dev n8 (48), stress n12 (36), new color12 (24) with planted and random graph families. Distinct seeds, shared generators; no canonical lineage claim. Exact labels from complete AC+DFS. No tuning using evaluation.

Evaluate on root AC state. Learned arms rank values using one frozen root score tensor during subsequent AC+DFS, no learned pruning. Controls: AC-LCV, exact functional projection when applicable (else AC-LCV), singleton AC projection, hard1/3/4 Boolean diagonal pruning followed by AC-LCV. All use 64 propagated-state cap; count separately root AC, search nodes and triple revisions (root AC outside search-node count, common to all arms). Record closure/refutation/censoring, actual runtime including feature construction, threshold false negatives/positives, tie-aware pooled AP, Brier and first viable value. Threshold diagnostics only over AC-surviving unary values; hard pruning is sound; learned predictions are not. No native replay requested: LBF-20F already establishes the fixed public-table assignment certificate. A later native domain must add a genuinely unknown successor outcome. No superiority gate; report failure if audit or theorem does not compile.
