## Research decision

LBF-10 changes the priority. Adding all native shortest actions to visited-state labels can hurt whole-proof completion on the structural family, even with adequate intervention exposure. The current objective combines a candidate-wise binary outcome loss with a log-sum-exp ranking term. Switching from a singleton to a multi-positive label changes both components and their effective gradients. The present experiment does not isolate which change caused the adverse policy result.

**Proposed LBF-11:** a frozen, train-only objective audit and then a matched loss-factorial experiment. Decompose the actual outcome and ranking gradients on exactly the same native multi-positive frames. Compare full-set BCE plus singleton ranking, singleton BCE plus set ranking, full-set BCE plus set marginal ranking, and a balanced positive-target ranking variant. Check within-positive concentration, valid-versus-invalid margins, gradient scale and candidate-pool degeneracy before any new calibration. Use the successful seed-107 single-action checkpoint as a diagnostic frozen model alongside the full-set checkpoints; do not select new evaluation outcomes using the exposed LBF-10 cohort.

Scientific status: development only. No architecture promotion or causal attribution to a particular loss component yet.
