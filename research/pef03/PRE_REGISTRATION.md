# PEF-03 preregistration | Frozen tied-attention recurrent history retention
Registered 2026-11-15 before the first PEF-03 training, heldout evaluation, or CI scoring.

## Lineage and purpose
- Parent theoretical source: Compactification-Theory PR #142, PEF-01/PEF-02/PEF-02S.
- Mathematical companion: MathCan PR #44.
- Neural implementation: `lsa.mini_transformer_probe.MiniAttentionMlpResidualBlock`, from this repository's pinned main commit `c8d254dde71d670b89057e568b4fb4b72647dd29`.
- Objective: measure whether observable history, causal sensitivity, and ordered-state Jacobians separate in a **trained parameter-tied causal-attention recurrent model**. The finite affine theorem is a null reference, not an architectural identity.

## Frozen protocol, before evaluation
- Architecture: one tied causal attention + MLP residual block, hidden dimension 16, two attention heads, MLP ratio two, alpha 1, beta 0.2. Each iteration receives an ephemeral new bit-token at sequence position zero and a carried memory-token at position one. Only the updated memory token survives to the next iteration. The bit token is discarded. An embedding lookup and two role vectors are trainable.
- Input: eight chronological bits, alphabet {0,1}. Label is the **two most recent bits** (four-way classification). Loss is only the four-way head cross-entropy. Earlier history receives no auxiliary supervision. Frozen training seeds: **17, 29**. CPU FP32 only, torch 2.10.0, AdamW learning rate 0.003, weight decay 0, 250 optimizer steps, batch 64, norm clipping 1.0, two CPU threads; no hyperparameter search or learning-rate adaptation.
- The full 256 histories are partitioned by the first byte of SHA256("pef03-v1:" + history bytes): 0..159 parameter-training, 160..207 probe-training, 208..255 heldout. All splits are disjoint by exact history, and identical for both seeds. Training examples are drawn with a fixed torch generator from the parameter-training pool only.
- The **frozen checkpoint is written and SHA256 recorded before any probe or heldout evaluation**. Re-reading the checkpoint must reproduce parameter hashes, and evaluation must not mutate parameter tensors. The randomly initialized model from the same architecture and a recorded independent initialization seed is a descriptive control.
- Fixed observational probe: intercept-augmented ridge with L2 penalty 1.0 on standardized hidden features; train only on the probe-training split; heldout bit-by-bit accuracies are reported for all eight historical positions. A majority-label baseline on the same heldout subset is always reported.
- Prior shift: evaluate stationary binary Markov histories with persistence 19/20, fair first bit, generated with independent fixed streams for 1024 probe-training and 1024 evaluation samples. Histories may overlap, so prior-shift scores are **source-distribution diagnostics, not history-disjoint heldout proof**. Include the exact analytic latest-bit-only Bayes baseline and a test-set latest-bit predictor. If the observational probe succeeds beyond 50%, compare to these baselines before inferring memory.
- Intervention measure: for every heldout history and every bit position, flip one original bit, re-run the frozen model with all other bits held fixed, and report the Euclidean final-memory difference and head-logit difference. Explicitly track flips whose counterfactual history falls in another split. No change to the source prior constitutes a causal intervention.
- Readout precisions: CPU float32 storage, and endpoint-only or after-each-visit tensor storage cast FP16 and BF16, returning to float32 for network arithmetic. This isolates **storage rounding**, not full low-precision compute. Do not equate with PEF-02 dyadic fixed-point scalar floor.
- Jacobian chain: at one predetermined heldout history (lexicographically first heldout), calculate each full 16x16 Jacobian of the recurrent memory-to-memory update at the actual visited state and an input-embedding directional derivative. Compose the ordered suffix Jacobian products, compare with direct autograd JVP of the entire recurrence for each temporal input token, and record singular values and relative error. Report commutative/norm-product proxies as controls. This is a *local differential* rather than the finite bit-flip effect.

## Registered outputs and interpretation
- Primary descriptive outputs: two-bit heldout classification accuracy, each historic bit's causal final-memory norm, 8-position ridge probe accuracy against the majority and prior-only baselines, Jacobian directional gain vs full discrete flips, and precision-storage causal sensitivity.
- Model task-success criterion: head classification accuracy >= 0.85 on the heldout split in **both** seeds; if missed, report the negative result and retain all original metrics.
- Diagnostic integrity criteria: checkpoint SHA unchanged through evaluation; exact source split integrity; identical intervention rest-of-history bytes; Jacobian product/full-autograd JVP relative error <= 0.05 whenever the reference gradient norm exceeds 1e-8. Unexpected failures cause nonzero CI exit and a retained failure receipt.
- The generated trained checkpoint and complete receipt are stored as CI artifacts (private repo); do not commit binary weights or expand computation budgets automatically.
- Resource bound: CPU-only hosted job, up to 12 minutes, no paid GPUs; training and evaluation at the stated fixed sample sizes; no merge or main changes in this campaign.

No early-stop interpretation: task accuracy and memory metrics remain descriptive and are reported even if model learning fails. Scientific scope is synthetic prompt history in one small trained tied-attention architecture. This experiment does not test production LMs or prove an information-theoretic theorem for neural transformers.
