# PEF-06 frozen coalition-intervention audit specification

Date: 2026-11-15. Posthoc analysis selected after PEF-03 through PEF-05.
This specification is committed before scoring the PEF-06 audit.

Source: the **original** PEF-05 registered model artifact from
[Actions run 43687506414](https://github.com/MoralityLabAI/LoopedTransformers/actions/runs/43687506414),
name pef05-four-seed-gradient-rescue-sealed-receipts, ID 14150782670.
Exact SHA256 of every checkpoint and the original registered negative
decision must be checked before any new frozen analysis.

Models: all **twelve** final frozen recurrent states (four seeds
101,109,127,157 × baseline/protect/sham). Fixed natural continuation
(0,1) after eight chronological input bits. Reconstruct original
seed-matched random initializations as controls.

Inputs: enumerate **all 256 binary histories**, with each natural
oldest-bit intervention generated by flipping bit positions 0..5
(individual) or each of their 15 unordered pairs. Positions 6,7
encode the supervised last-two-bit task and remain fixed.
Model evaluation is batched once per checkpoint over all histories.

Measurements: empirical single-bit and two-bit task-class change
rates; the number of *pair-only* class changes where neither
corresponding single flip changes the task class; hidden state
finite-difference interaction \|h(x^ij)-h(x^i)-h(x^j)+h(x)\|₂;
the analogous four-logit interaction; head accuracy on the fully
enumerated finite cube, task-label invariance, and source-trunk
random-init contrasts. Report every seed/arm and all 15 pairs.

The theoretical three-paper coalition latch F_3 on the same six
oldest-input bits has exactly zero individual-bit sensitivity
at all zero and three disjoint two-bit activation coalitions;
its exact independent noise law is the finite analytic control.

This is **descriptive, posthoc mechanistic measurement**, not a
new heldout training result or a preregistered causal rescue
success test. Every input in this 256-point toy source family may
have appeared in prior research. The network's output head is
trained only on the last two bits. A pair-only *predicted task-class*
change does not establish the hidden model implements the latch
or that a task capability improved.

No gradients or parameter updates are allowed. Verification:
checkpoint SHA256 unchanged, source split intact, all counterfactual
newer bits unchanged, full model weights SHA256 unchanged, and
reproducible JSON evidence in hosted CPU GitHub Actions.
