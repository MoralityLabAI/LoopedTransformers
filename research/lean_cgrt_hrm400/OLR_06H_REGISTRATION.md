## Counterfactual action space

All actions share the same exact demand-ledger prefix, 128 fresh concrete expansions or earlier terminal. The search state includes the discovered undirected rewrite graph, union-find components, unexpanded frontiers and already found paths. The prefix is deterministic and independently compared to the 06E runner. This state is a proposal ledger, not a proof kernel.

At the prefix checkpoint, list the nonempty active frontier components that contain the witness or an unresolved target. Canonical action identity is the minimum endpoint slot belonging to that component, witness slot 0 then target slots 1..K in original roster order. Action "continue" follows the original demand controller. A component action spends up to 64 additional expansions on the chosen component, following its merges via the representative endpoint. Within that component choose the minimum (discovery level, word) frontier entry. If all goals close, stop; if its frontier is exhausted, release control to the demand scheduler. After the block, run the ordinary demand controller to cap 512. Preserve the exact graph, paths and counters throughout. No restarts, duplicate free prefix or hidden reference paths. Each source counterfactual clones the checkpoint and pays the same prefix in its reported path cost; offline branching is teacher generation work, separately reported. Terminal/censored prefix has only the continue action.

All leaves retain the <=15 rewrite cap and terminal exact witness. A capped miss means no bounded proof proposal, never refutation. Native Lean independently replays each distinct successful leaf path and compiles original conjunctions from only selected leaf lemmas. Freeze plans before native grading. The entire counterfactual table is generated for source and fresh evaluation to measure the hindsight envelope. Any deployable control selects its action solely from the common prefix, before that table is generated. The table is not a deployed policy.

## Gate

TRAIN and fresh evaluation separately: at least 10 percentage points of full-closure hindsight headroom over the best fixed/deployable same-information control, and at least 20% unsolved by that best control. In both splits, at least 20% of roots must have a nonterminal prefix with two or more viable actions. Report source calibration separately; no parameter selection on fresh roots. This is an optimistic headroom test, not evidence of learnability. If the gate fails, close this block-action family; do not change caps or block size posthoc to claim a pass. If it passes, use the frozen native source action-value table and graph features for a new registered reader fit (matched one-way, one-visit, pooled/direct and ridge controls). Do not reuse the fresh evaluation panel for tuning. No neural model fits, FSI-01 confirmation, or architecture promotion in 06H.

Protocol tests: demand continuation identity, component-action legality, exact graph/path preservation, work offsets, terminal prefix, teacher independence and native conjunction verification.
