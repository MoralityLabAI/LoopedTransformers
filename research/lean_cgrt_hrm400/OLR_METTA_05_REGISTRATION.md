# OLR-METTA-05: native addressed receipt memory / history aliasing

**Registration:** 2026-11-24, before generation or model scoring.  
**Parent:** [04D frozen carry audit](OLR_METTA_04D_CARRY_RESULTS.md).

## Question

Does explicit obligation-addressed writing help a compact weight-tied attention model retain verifier evidence across several simultaneously pending native Lean goals? In 04D the current stage/budget packet already determines the correct scripted tail. Here a restricted current observation alone is provably insufficient. A native receipt history carries the missing information. An exact explicit-history map is deliberately provided as a transparent algorithmic ceiling.

## Native family and observation contract

One theorem contains K abstract goal predicates R_i and a conjunction of those goals. Each R_i has two local rules r_(2i), r_(2i+1), each opening an equality guard and indexed P c and Q c obligations. Universal h0 : forall n : Nat, P n and h1 : forall n : Nat, P n -> Q n discharge the indexed tail. Exactly one branch per address has a true numerical guard. All complete proofs use four tactics per goal after conjunction setup.

The host splits the conjunction, saves the joint pending state, focuses each address in a permuted order, and executes a two-call speculative probe of a randomly selected branch (apply rule; rfl). After each probe it restores the same untouched joint state, even on success. The model receives the address, attempted branch and actual binary native verdict as a typed receipt. Native Hyperon 0.2.10 matches current, unique, native receipt facts, excluding marked stale aliases. It does not establish theorem truth. Synthetic rejected aliases are represented by payload-free veto tokens. The exact record set is checked against a Python reference. A fixed delayed query phase requests a permutation of all pending addresses. Model-visible packets exclude raw theorem numerals, root identity, raw hypotheses, private labels and current receipt history after the query starts. The explicit history baseline gets the same admitted receipts as a transparent map.

Each pair uses identical addresses, probe branches, probe order, recall order, delay, and model-visible query packets. Its two worlds complement every guard winner. Thus a deterministic stateless reader with no previous receipts must have 50% address accuracy over every pair and at most one full theorem completion per pair. This is deliberate observation aliasing, not equivalence of full native Lean contexts. The exact receipt map uses the tested branch on acceptance and its complement on rejection **within this registered unique-winner grammar only**.

Every root requires a native reference closure, one independently checked rejected opposite guard per address, and standalone Lean certification. The probe stream is generated live, choices frozen before final proof execution, and the exact native prefix and committed continuation are replayed. Identical selected action vectors at a root may share a native replay; policy decisions are counted separately. Report grading checks separately from policy calls. Setup K-1, probe 2K, final 4K yields cap 7K-1. Wrong final branches are terminal; no free corrective probe. Focus, restore, Hyperon and independent grading are separate meters.

## Frozen allocation

- Seed 20261208, distinct namespace OLR-METTA-05. Train 32 pairs (64 worlds), K=3; development 12 pairs (24 worlds), K=3; load transfer 12 pairs (24 worlds), K=5. Address alphabet 0..4; K=3 active subsets sampled without replacement. Operand band 45..60 (disjoint from earlier 01/04 bands); exact ordered numeric root specifications disjoint across split. Both worlds always grouped.
- Pair complements all branch bits, and fixes a focal recall address and a different sham address independent of truth. Source training can use only native-verified TRAIN histories and full reference closures. DEV and load-transfer native verdicts never update weights. No later checkpoint selection.
- All learned arms fit seeds 17/29/43, 160 AdamW updates, batch size 16, width 24, one physical weight-tied self-attention/MLP block. Each receipt or veto event advances one shared cell; each recall query applies one read cell. Slots have a public fixed address encoding. Both neural memory arms compute identical token shapes, attention, MLP, write proposals and readouts; the addressed arm gates the write to the receipt address, the dense arm writes every slot on admitted receipts. Both skip writes on vetoes/delays. Same initial state dictionary per seed, minibatch indices and optimizer. The only trainable-arm difference is the hard write mask.
- Controls: trained dense and addressed recurrent models, learned explicit-map MLP (same verified receipt information, smaller/different compute), exact explicit map, fixed r0, frozen addressed model erased immediately before recall. Report whole proof completion, address and complete-pair accuracy, target-focal accuracy, actual tactic calls, model event visits, native receipt queries and seed outcomes. Addressed versus dense has matched active compute per root because every history and recall event is fixed; the explicit reader is not compute matched.
- Frozen causal test: same addressed checkpoint on unmodified history, flip the one focal receipt verdict, or flip one nonfocal receipt verdict. Only the **model input** changes; native receipts and Lean truth stay original. Each intervention changes one sign bit by equal magnitude and uses the same number of event visits. Other obligations are completed by the exact receipt map, so the target-only full-theorem endpoint is attributable to the focal choice. Report focal action changes and proof completions; a routed architecture can show this effect by construction, not an emergent learned semantic mechanism.
