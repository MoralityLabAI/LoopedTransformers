# OLR-06B.1 paid-relation allocation: preregistered synthetic CPU pilot

Date: 2026-11-24. Implements the B gate of OLR_06_WORK_ORDER.md. Scope is a finite-horizon synthetic decision problem with exact signed receipt closure. Native Lean semantics and FSI-01 confirmation remain separate.

## Environment

Each public node denotes an exact known component, weighted by its number of obligations. An anchor fixes its sign; a successful relation joins two components with a consistent signed edge. The hidden signs and query successes belong to the simulator; a censored query installs no fact. Every action spends its public integral cost once. Success probabilities are independent, known, and fixed before policy selection. STOP always legal. Initial anchored nodes, weights, candidate endpoints, costs, and probabilities are public.

For this objective, resolved coverage depends only on which queries succeeded, so the pair of attempted and successful bitmasks is a sufficient statistic. Signed closure is independently checked in sampled executions. The exact reference computes a finite-horizon Bellman optimum over all legal query outcomes. Terminal utility is resolved-weight fraction minus 0.01 per unit of paid cost. Report resolved-weight fraction (primary practical coverage), utility (optimized objective), full-resolution probability, attempted cost and number of queries separately. Exact expectation is the primary evaluation method; a fixed, independently sampled common outcome table per root is a separate execution audit.

## Allocation and model comparison

- Seed 20261212; 160 TRAIN roots with five quotient components, 40 DEV roots with five components, 40 transfer roots with six components. TRAIN/DEV chain and fork query layouts, transfer long-chain and diamond layouts; size and budget shift accompanies topology shift. Canonical public weighted graph signatures must be disjoint under node permutation. Do not treat all query states or seeds as independent roots.
- At each source root, enumerate reachable public states and exact expected Q-values. Use the initial state and up to 31 uniformly sampled other states (fixed per-root sampling seed). No fitting on DEV/transfer states. Predict exact utility-to-go relative to current STOP value, masking illegal offers. Include STOP as an action.
- Three seeds 0,1,2; 240 optimizer updates, batch 32, AdamW lr .002, weight decay .005; width 48, 4 tied visits. Candidate graph contains current exact component tokens, unattempted affordable query tokens and STOP. Each query is incident to its current endpoint component(s). All models receive the same features, full incidence and exact immediate expected gain. The incidence cell has separate component-to-query and query-to-component projections; both computations run even in masked arms. Immutable features reinjected each visit.
- Arms: bidirectional, component-to-query only, query-to-component only, dense tied attention, full-packet direct MLP. Compare bidirectional versus one-direction with exactly identical width, initialized state and active tensor schedule. Dense and MLP have different compute; report parameter counts, visits and analytic MAC estimates (not measured FLOPs) plus CPU wall times. All neural scores determine only legal query rankings.
- Reference policies: STOP, one-step expected-utility greedy, two-step expected-utility lookahead, full Bellman optimum. Exact static anchor knapsack is a separate calibration family. Demonstrate a deterministic delayed-gain example where greedy and two-step underperform full search.
- Score fixed trained policies by exact expectation on all reachable outcome states, batching neural forward calls. Replay one actual synthetic execution per root/arm with common hidden sign/outcome seed and independently verify signed closure. Record all source/model/registry hashes. Report per-root paired contrasts and descriptive root bootstrap intervals. No 5M promotion or mechanism success from this pilot. The synthetic Bayes-optimal reference is a ceiling; the neural question is approximation quality and cost at bounded model compute.

## Gate

Unit tests compare the Bellman recurrence to independent explicit signed-ledger enumeration on small cases, verify action legality, signature invariance, censored receipts and delayed-gain planning. No score is a Lean certificate. If direct or short-horizon exact controls close the gap, refine the query distribution or abandon neural allocation on this class. Real semantic uncertainty and native proof completion are required for the next gate.
