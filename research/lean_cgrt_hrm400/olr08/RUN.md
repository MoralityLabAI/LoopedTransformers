Fresh calibration/evaluation file roster is explicit in `run08.py`. All 62 known spent files, old declaration names and exact goal hashes from Fable and 07A are excluded from fresh sampling. Fresh files in previously tested Array/Vector/Fin/UInt families support new-file evidence; BitVec is a new family in this package's lineage. SInt is reserved. Report family overlap rather than claiming entire-family novelty. Verify against any additional spent files identified by the repository's other campaigns before full launch; if a conflict exists, register exclusions before outcome collection and use a new contract.
- Fresh selection: up to 12 terminal T and 6 first-multistep R states per file, deterministic seed 20270129, at most one selected declaration in fresh registry. R source theorem is known certified by its original Lean elaboration; no claim its first human tactic closes. Select before observing menu outcomes. Exact goal-text exclusions do not imply semantic independence. Source registry and role hashes frozen. T human replay uses 20,000 thousand-unit cap, independent candidate cap 500. Two fresh menu passes, verify scope and receipt categories. No label or inference use of the human proof text. Only scored roots unresolved by all 12 menu actions enter the argument-search cohort. Archive all exclusions; no resampling on candidate results.
- Gate 0: native scope sentinel and original exact 07A/B reissue receipts. Full source T-human rate >=95% in both TRAIN/CAL, at least 20/10 scored human audits respectively; fail closed before fitting. Fresh evaluation validity reported separately. Smoke uses no research gate.
- S1 uniform cost, S2 Fable hand costs, S3 counted prior from newly native-certified S2 TRAIN paths and attempt logs, S3c cost-aware counted prior using actual raw heartbeat averages. Fable's exact premise proposals, same enumerator caps (40 rewrite and 10 apply requests, 24 rewrite and 6 apply selected for actions; capped locals/definitions as in search08.py). Literal duplicate tactics removed. Depth3, 300 attempted tactics, 1200 native RPCs, 512 million raw heartbeats per policy/root. Stop at first certified complete proof, count failed/open attempts. In-flight overshoot is charged and receives no closure credit. Native handler heartbeats and wall time for every request, including premise enumeration, graphs, lemma graphs and certification; Python feature/inference time separately. Opening/elaboration and independent replay recorded separately and must be included in any end-to-end runtime comparison. Every credited path is replayed and certified in a fresh pre-command Lean process. No equivalence claims from PP equality; no cross-path state dedup until typed-state identity is independently justified.
- Gate 1: require >=40 hard TRAIN roots, >=24 hard CAL roots; strongest fixed control <=80% closure on CAL and S3 at 1200 attempted tactics (fourfold RPC and heartbeat caps) >=10pp above best 300-attempt control. Longer run is an offline headroom reference, not a deployable same-budget policy. New cohort and stricter accounting can alter Fable pilot rates.
- Gate 2: >=64 source action-label frames from successfully replayed S2 paths. Exact event-ID alignment supplies counted-prior labels, rather than fuzzy script reconstruction. The empirical counted prior is a ranking prior on sampled attempts, not a calibrated probability of mathematical truth. Save native replay/feature receipts and source tensor dataset. No held-out outcome data used to fit. Ranking objective is cross-entropy on the actual native-certified path action among its entire enumerated menu; other menu entries are competing proposals, not logical negative facts. Width40, hashed node/edge/action and bag features, 3 tied rounds of directional messages with immutable injection. Hash/fuel-limited graph is only a representation, never proof identity. Linear same hashed bag/control features; local zero-visit; bi1 one-visit; one_way masks reverse contribution; ff3 masks both message directions while executing same recurrent block/edge ops; sham uniformly relabels within the legal menu. All except linear share parameter initialization/sampler (test enforced). Local and bi1 differ in active compute; ff3 and one_way are same-operation-schedule ablations. Three seeds17/29/43, 400 CPU AdamW updates, one variable-sized graph frame per update, lr .002 wd .005. Model predicts residual on counted S3 costs. All neural fits have 122,881 parameters; linear 391. Explicit cap on feature graph size with logged prior fallback. No forced training if gates fail.

No free extra search. Prior-only S3 uses full same budget. Alternation only bounds relative tactic count if other caps do not bind and both queues remain live; no twice-wall-time guarantee.
