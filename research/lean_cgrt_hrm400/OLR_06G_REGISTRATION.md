## Supervision and selector

Execute the fixed menu on source roots only; check public path legality and native replay/compile every distinct proposed successful leaf and full conjunction. A bounded miss is a censored search outcome, not proof of falsehood. Teacher utility for each complete schedule is indicator(full) + .25 * resolved-leaf fraction - .01 * total work / 512. All actions share this utility. The offline teacher runs many strategies to label one source root; that expense is training overhead, not a deployable policy cost.

Represent public syntax with five padded obligation tokens and six equation tokens, preserving actual target and rule order. Each obligation receives full witness/target words, pair occurrence histograms and cheap mismatch/branching statistics. Each equation receives both public pair endpoints and a positional index. Incidence weights from occurrence counts at original endpoints; no neighbor exploration, pattern database or native proof result in the feature packet. Count pair-symbol scans and CPU feature time, and inference time separately from search budget. No privileged generation distance or lineage ID in features.

Learned arms: width32 tied obligation-rule incidence cell with three visits and immutable feature injection; one-direction mask executing identical tensor ops; one-visit bi control; pooled local MLP; dense tied attention; full-packet MLP. All have the same full input packet before architectural pooling. Fit seeds 17,29,43, 160 AdamW steps, batch16, lr .002, weight decay .005, smooth-L1 utility regression across 12 schedules. No query-side fitting. Include deterministic ridge on standardized complete flattened packets (dual solve, regularization 16), and train-feature nearest-neighbor (five nearest, mean utilities). The fixed per-load reference selects by mean TRAIN utility. Each learned predictor and simple estimator mixes its prediction with that fixed per-load training utility vector using coefficient from 0,.25,.5,1 selected by highest mean calibration utility, tie smaller coefficient. Freeze selector weights, mix and choices before computing evaluation outcomes.

## Evaluation and gates

For each new root, compute/freeze all selector actions first. Then run the fixed schedule matrix for reference, native verification and the offline hindsight envelope. A selected policy inherits only its chosen schedule's actual work, receipt paths and success; the evaluation matrix is grading overhead. Never choose on the matrix after seeing outcomes. Include every fixed arm, source-fixed per-load selection, ridge, nearest-neighbor, all trained arms and unrestricted independent reference. Hindsight envelope separately reported, with best fixed per-panel comparator explicitly posthoc. Evaluation also checks actual search time and selector overhead.

Primary: complete native conjunction at 512 total work units. Secondary: utility, coverage, work, selected arm frequencies, calibration error and CPU timing. Independent root is statistical unit; seeds are repeated measures. Report descriptive paired bootstrap intervals and per-seed outcomes. Bi versus one-direction matches params/init/sampler/ops; bi1/local/dense/full do not match all compute. A useful developmental result needs positive effect beyond strongest source-fixed/classical selector and >=5 percentage points gain over the best simpler learned reader on fresh roots, consistent seed direction; no FSI-01 or architecture promotion. If the best fixed restart consumes the hindsight gap, or simple selection ties/defeats recurrence, retain the exact schedule portfolio and retire the neural mechanism here. No 5M model based on this study alone.
