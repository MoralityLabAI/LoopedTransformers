# OLR-06C.1: native scoped Boolean semantic-query preflight

**Registration:** 2026-11-24, before root generation, training, or evaluation.  
**Parent:** [06B results](OLR_06B_RESULTS.md).  
**Scope:** a small native engineering and source-supervised applicability pilot. Exact finite Boolean evaluation is an intentionally strong same-information reference. This is not a general dependent-type reasoning or promotion experiment.

## Task

Each obligation is an open Boolean expression in three scoped variables x,y,z. The original root asks for a constant witness for each expression: a conjunction of (exists b : Bool, forall x y z : Bool, E_i = b). All registered expressions are constant functions, though their public syntax contains variables, Boolean operators, and nested subexpressions. The model gets the complete prefix syntax, node and offer incidence, signs and budget. It never gets generator truth or query outcomes as input to the source fit.

An anchor query proposes a specified constant sign for one expression. A signed relation query proposes equality or complementation between two expressions, in both orientations. Native Lean 4.19 evaluates a fixed tactic macro (case-split all three Boolean variables, then reflexivity; for a relation also split the conjunction). Each attempted macro spends one query unit. Native accepted receipts require empty goals, kernel acceptance and no axioms. Rejected macros install no negative proof fact. Because the finite registered grammar has exhaustive truth-table semantics, the independent evaluator checks all eight assignments, and every native verdict must agree with it. This justifies using failed checks as predictive observations in this grammar's Bayesian planner, but not treating them as kernel certificates or extrapolating to arbitrary tactic failures. Distinguish compound queries from elementary tactic FLOPs. Relation macros prove two orientations and may cost more wall time. Record timings and counts.

All successful positive receipts enter a verifier-owned signed ledger. Exact closure transports anchors across admitted signed edges. The final independent Lean compiler may use only the selected positive receipts to construct explicit witness terms using existential introductions and equality transitivity/complement congruence. Partial coverage is separately certified for resolved obligations; a whole-root success requires the full original conjunction. The independently compiled source re-proves the admitted receipt lemmas in the original scope, then composes them, not a fresh brute-force final proof search.

## Allocation and policy

- Generator seed 20261216; 64 train roots and 24 development roots, four expressions each (chains/forks); 24 transfer roots, five expressions and deeper syntax (chains/branches). Randomize node order and offer order. All expressions within a root are distinct. Split by canonical multiset of public ASTs; exact prefix-expression identities are disjoint across all roots, beyond the shared variable names and operators. Allow both signs of each spanning-tree relation and both signs of a single anchor; add one public extra anchor if it fits the 12-offer bound. Budgets n or n+1. Native truth table confirms every root has a valid n-query connected plan.
- Train source-only classifiers on the full native acceptance labels of candidate queries, 3 seeds 0,1,2, width 48, 200 AdamW steps, batch 16. Output independent sign probabilities per expression; train with Bernoulli query likelihood derived from these probabilities (anchor or equality/complement). Model never observes source witness truth labels directly. Compare shared local expression MLP, full-packet MLP, bidirectional incidence, one-direction incidence (same initialization/compute) and tied dense attention. Common complete prefix encoding. The local reader uses its own syntax and is a deliberately strong simplicity control; full-packet control gets all data.
- Freeze the fitted models and per-root prior probabilities before evaluating native query outcomes. One shared two-step receding-horizon planner enumerates possible sign assignments and conditions on actually observed success/rejection under the registered exhaustive semantics. Only positive proof receipts count toward certified coverage. Terminal utility = 1(full coverage) + .25*coverage fraction - .01*paid queries. Compare uniform prior depth 2 and full horizon, public truth-table depth 2 and full horizon, and all fitted priors at depth 2. The public truth-table solver receives exactly the same syntax and is a same-information algorithmic ceiling. It is not a hidden-label oracle.
- Each root/action native check executes once plus independent fresh replay; deterministic outcomes reused as a cache during adaptive policy execution. No policy sees unqueried native outcomes. Report distinct actual native executions separately from policy trials, per-policy paid macros, accepted receipts, full certified roots, partial coverage, source classification NLL, and actual native timing. Independently compile unique selected certificate subsets. Store provenance, masks, priors, decisions, receipts and theorem source with hashes. Primary endpoint full certified root count; secondary coverage and query cost. Model seeds are repeated on the same independent roots.
- Engineering tests: complete finite syntax roundtrip, canonical split uniqueness, independent signed closure, Bayesian planner compared with brute enumeration on tiny roots, actual Lean acceptance/rejection and two-way relation proof, independent positive-only transport. Same-information exact normalization is mandatory; no mechanism/FSI-01 claim. A learning gain over weaker controllers is insufficient for 5M promotion. If semantic evaluator saturates, proceed to opaque rewrite witnesses and resource-bounded native search rather than scale the Boolean task.
