# COG-09: causal carry-site calibration (development)

This is a stacked follow-up to COG-03 (PR #394). The two original depth-four checkpoints are frozen and hash checked. Every neural arm runs the same four shared transformer cells per decision; the reset-history reference has the same depth. The symbolic goal-ancestry policy is a separately labeled structural ceiling.

The intervention site is the gated projected previous-decision state immediately before addition to the current input. Fit a single mean-difference direction per checkpoint using only the original 64 training roots, restricting labels to ready, previously unproved candidate rules. Goal ancestry is a symbolic training label, not an input to the policy. No optimizer updates or probe/dose selection on pilot outcomes. The direction could encode any correlate of useful rules; causal specificity must be tested.

At this site erase the centered projection along the fitted unit direction. Four fixed random orthogonal directions receive an additive perturbation of exactly the same signed per-token magnitude. The sham directions are destructive perturbations; they control site, physical L2 dose and cell calls, not the semantics of a harmless placebo. The original unmodified forward is checked against the explicit-site forward. A separate teacher-forced readout compares all six directions at identical states, and the online comparison independently follows each policy through its own history. Matching is exact at a common state; divergent rollouts can receive different absolute doses and execute different total numbers of decisions.

The protocol fixes 64 new deeper development roots from the pinned generator, two existing seeds, 16 charged verifier calls per run, one primary outcome and four shams. The tighter budget reduces the ceiling seen at 24 calls. Primary endpoint is completion AUC: a proof completed on call k receives (B-k+1)/B, failure gets zero. Root-average baseline minus erasure is the effect; each root's worst absolute sham contrast across four shams and both seeds goes into EvalMath's 95/95 tolerance envelope. Fixed-state useful top-action rates and useful softmax mass are secondary diagnostics. AUC is bounded and has resolution 1/32 after averaging seeds. Record every attempt, all negative outcomes and complete arm/seed/root coverage; use EvalMath's separate finite verifier to replay every episode.

The preflight uses the pinned EvalMath power planner with a 0.10 scientific floor and a 0.20 target. Its independence assumption is conditional on independently generated roots, fixed checkpoints and the generator family. There is no sealed confirmation in this commit. It deliberately does not generate or score a confirmation cohort, even if the pilot suggests a large effect. A new prospective protocol must pass power planning with a separately managed sealed readout. The source-pinned public pilot alone cannot certify generalization or causal mediation. This stage does not recompile proofs in Lean; its proof validity receipt is an independent finite Horn replay.

The workflow checks pinned source revisions, runs unit tests, evaluates all arms and retains the full raw artifacts. It uses two CPU threads and a bounded call count; no external API or accelerator costs. To reproduce, see the workflow command with local pinned DataGoblin and EvalMath checkouts.
