# NAN-WINDOW-66 integrated device lane

This runner executes the same 12-root NF4 ROUTE58 experiment with WINDOW66
instrumentation. It retains the published-source, process closure, device,
RAM and exclusive-lane prerequisites. Both entrypoints share the same NF4
artifact slot so the registered causal question is run once. Existing
workers and queued jobs keep their own execution bytes.

Use the existing paired cached native path to qualify all 72 registered
prompts through an independent gold process. The device preflight first
closes depth and cache checks. It then compares the additional capture
against the original full head and native states for both rows of one
paired B2 prompt. The delayed instrument reuses the established signed
active and sham continuations. The 24 fixed world slots close in source
order, including all refusals, with exclusive records and hash-bound
journal entries. The worker verifies the checkpoint and quantization again
before writing its terminal receipt.

The host first verifies the inherited ROUTE58 endpoint against terminal,
native competence, dose and full-head gates. It then binds every WINDOW66
episode to that same immutable terminal and journal, checks each layer
allocation and actual final score, and averages the two worlds within
each complete root before averaging roots. The final native effect and
the layer-by-layer restricted-head effects are both recorded. Synthetic
receipts are only accepted by the dedicated fixture. Refusals and
one-world closures retain their original denominators. The protocol
uses zero formal tests.

`python -m experiments.nan_window66.lane --check-admission` checks local
prerequisites after the runtime freeze without loading Torch or a model.
The CUDA entrypoint additionally verifies the published research-branch
manifest. The CPU host fixture exercises all slots, an all-refused native
gate, a partial root, and tampered records while pretrained device
results remain pending.
