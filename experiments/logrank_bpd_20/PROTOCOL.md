# LOGRANK-BPD-20 development protocol
Fresh worlds: n=12,48,96; relabeled chain, two-hub chain, global random triples; three seeds per size/family (200000+1000*n+100*family+i). Two unary and 3n triple observations; uniform hidden state; paired known BSC .15/.35. Refuse max bag scope >6 before table allocation. Four epochs of 16 distinct pair queries: first clustered by source; subsequent batches reuse eight previous pairs and add eight new pairs (not necessarily globally novel). Before epochs 1,2,3 acquire one independently noisy repeat of a public existing observation mask, preserving graph topology. Same observations, query order and update schedule across arms. Compare direct upward contraction per query plus root; on-demand source-batched signed path contractions with unsigned separator caches: LRU and online value/byte at 16/64/256 KiB, LRU at 1024 KiB (full-admission reference), LRU flush at 64 and 1024 KiB. Selective invalidation deletes every cached direction whose source-side component contains the changed factor owner. Value uses observed cumulative requests times static cold subtree arithmetic contributions divided by actual logical charge, including incoming entry in eviction choices; no future query/answer data. Cache logical charge: recursively counted dict/keys/values, edge tuple and ints, plus fixed 256 B per message; no Python allocator/RSS cap, temporary signed/unsigned contractions and policy metadata excluded. Track bytes, hits, misses, invalidations, evictions, rejections, arithmetic contributions, runtime including updates/selection, exact outputs. Timings sequential within each condition; process RSS descriptive, not per-arm. Exact direct replay all admitted outputs; independent exhaustive n12 and chronological frontier DP at larger structured widths on each evidence epoch. Independently verify invalidation set and cap snapshots. All dense refusals retained. Development only, no model training or causal/confirmation claim, independent unit world, no protected data. Primary comparison: 96D hub-chain at 64 KiB, value vs LRU on total arithmetic and elapsed time; all other strata and arms retained. No tuning after readout.
