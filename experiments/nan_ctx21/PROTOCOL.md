## Source design and endpoints

Twenty newly seeded independent source graph roots: four CAL resource-profile
roots and sixteen DEV roots. Each root has two permutation worlds with distinct
one-hop answers, made by swapping exactly two outgoing destinations. Whole
target graphs are distinct from the named previously exposed graph fixtures;
no held-out source is used for exclusion, overlap checks or generation.

Each prompt has many named 16-node graphs; the final question names one graph
and Start. All distractor graphs are valid sources for other possible queries,
not padding prose. Three fixed worked examples explain one-edge lookup. For
each root/4096-or8192-token budget, use a fixed binary search over graph counts
3..160 with the pinned tokenizer, testing the longest position/world/arm variant
at each count. Preserve the full search trace. Token-boundary merges need not
be monotone; no global-maximum count claim is made. Every final selected variant
must fit and be within192 tokens below budget.
No neural outputs, correctness filters or source retries enter count selection.

Every DEV root/budget uses early/middle/late target placement, both worlds,
and main/literal-copy/whole-target-erased arms:576 DEV contexts/backend.
Every CAL root/budget uses middle placement, both worlds and all three arms:
48 CAL contexts,624 total/backend. The same base graph draw and distractor order
are reused across lengths; all repeated variants remain correlated.

Erasure replaces ALL16 target-graph destinations by question marks; retaining
other target edges could leak the answer through the permutation complement.
World A/B erased prompts are byte-identical and still have distinct host answers.
They receive independent fresh model forwards, never cached replies. Copy
controls retain the long source and explicitly supply the correct final label.
DEV paired answers balance all16 labels; CAL spans8 labels and is a resource
profile, not a population estimate or new competence gate.

Primary readout: one unconstrained full-vocabulary greedy token at native loop2.
Secondary: loop1, separately. Use the already fixed anchored COMP14 A–P grammar
with64-character bound; do not scan explanations or add generated continuation.
Report every split/budget/position/arm/loop, format failures, correct worlds,
both-world-correct roots, missing coverage and erased-repeat token equality.
No model answer or CAL accuracy gates DEV. Resource/execution stops do gate
remaining coverage as below. No new pass/fail competence screen is invented.

large model remains. NF4 then BF16, one large model at a time. Existing pinned
offline snapshot and software only; zero neural retries. Keep all22 NF4 decoder

attempted/orphan files, error type and all missing cases. No lower-precision,
