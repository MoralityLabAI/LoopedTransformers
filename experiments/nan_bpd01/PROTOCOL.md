# NAN-BPD-01 frozen development protocol

This is a new development-only campaign. Existing v014/v015 text, historical
receipts and the original 168-case ARG-03 test are preserved. The protected
test must not be opened, regenerated, used for exclusion, or inferred upon.

## Falsifiable question and independent unit

Primary proposed contrast: donor-specific, independently verified future@12
recovery under a selected frozen BPD write minus physically matched random-dark
writes. Minimum meaningful difference: 0.15 solve fraction. A source-generator
world is the independent unit. Recipient/donor variants, tokens, phases,
directions, temperatures and the two backend executions are clustered measures
of that world, not independent model replications. One checkpoint is studied.

Four fresh development roots and two separate calibration roots are a bounded
instrument pilot. They cannot supply the 59 independent sham roots needed for
a nonparametric 95th-percentile/95%-confidence sample-maximum bound, or the
20-root minimum FSI confirmation gate. No confirmation readout is generated.
The prospective confirmation plan requires at least 60 new worlds and separate
sham calibration. Its population, case count and resolution must be redesigned
from empirical pilot data rather than treating this plan as a power result.

Before compute, run the EvalMath strict planner with no empirical pilot and
archive its refusal; do not invent matched shams or import synthetic BPD shams
as Nanbeige calibration. Re-run on actual development-root phase/sham outcomes
where available, explicitly labelling that contrast rather than the unrun BPD
primary. Evidence remains exploratory/power-limited. FSI-01 cluster reporting,
exact paired accounting and Holm across the complete tested family are required.

## Phase 0: numerical and memory gates

Keep the BF16 166144-by-3072 head on CPU. Transfer all vocabulary rows in chunks;
accumulate stable full-vocabulary log-sum-exp and exact selected operator logits.
Never replace the denominator with a four-operator softmax. Preserve the sixteen
candidate-prefix rows and original 64-program enumeration. Compare against the
full GPU head before loading the checkpoint: operator logits, normalizers,
program scores, temperatures, nondivisible chunks and extreme-logit cases.
The measured float32 logprob/program-score tolerances are fixed in config.json.

All pretrained parameters are frozen. BF16 streams decoder layers; NF4 uses
the existing PR151 NF4 double-quantized effective decoder. CPU-computed RoPE,
candidate microbatch 1, prompt format and software are paired. A 75% CUDA
allocator cap protects the 4 GiB device; failure is recorded rather than
changing scientific outputs. Record allocated, reserved, sampled dedicated and
sampled shared GPU allocations separately. Shared allocations do not quantify
paging, and successful inference is not a device-residency certificate.

## Source-bound task and competence gate

Generate only new named NAN-BPD development worlds with the exact algebraic
oracle. A pair shares input series, query, topology, public field structure and
canonical candidate sequence length. Donor/recipient programs have the same
operator multiset but different verified query futures. Reject and count target
collisions, source ambiguity and length mismatches using source information only.
Retain all attempted pair counts; never replace a pair based on model success.
The sixteen program-prefix rows and fixed verifier budget 12 are unchanged.

Use the snapshot's native chat template for the main source-only task; compare
the inherited bare ARG-02 prompt as an input-format control on the two fixed
phase-intervention roots. The chat template, source grammar and all seeds are
fixed before any checkpoint outcome. No hidden program or future is in a prompt.
Freeze per-position temperature choices from {0.5,1,2} on calibration roots only.
Report native single/two-pass, calibrated, open-loop, equal-compute, source-input
counterfactual and context-blind positional-frequency controls. No DEV fitting.

Before native BPD fitting/interchange, require native two-loop future@12 >=0.5,
at least two pairs with both clean continuations future@12-correct, and at least
one pair with both native top-one futures correct. Distinct pair targets make
the latter impossible for an input-blind constant-program predictor. A floor
failure blocks dictionary/behavioral mediation, not engineering tests. Report
all generated pairs, eligibility and collisions; do not turn unrun arms into 0.

## Phase-conditioned observation and interventions

The predeclared candidate is raw layer 21/channel 2279, with channels 2278,
2280,173,1531 as neighboring/random controls. Record both raw final-layer and
post-RMSNorm activity at loops 1/2, by token position and world. Tokens do not
increase n_units. Calibrate loop-two replacement values on CAL activations only.
Separate phase-marker variation from source-donor variation; correlation is not
causal reasoning information.

On recipient examples of DEV roots 0/1 only, compare channel suppression,
CAL loop-two replacement, translated equal-dose neighboring/random-channel
writes, same-dose dense context-dark random writes and a zero sham. Only the
eight unscored context positions may change in current-dark arms. Use actual
BF16-rounded physical L2 dose, <=0.5% relative mismatch, exact scored-tail state
identity, and measured chunked full-vocabulary current-readout comparison.
Keep ineligible/zero-dose outcomes and report dose failures. Full-state donor
and source-input counterfactuals may change immediate readout and are labelled
separately. Whole-layer normalization and raw/post-norm statistics are audited.

Global diagnostic arms edit channel 2279 at all positions (toward zero), and
translate that same coordinate pattern to 2278,2280,173,1531. They deliberately
change the scored positions and are not current-dark interventions. Context
arms are suppression/replacement on 2279, translated patterns on 173/1531,
and dense random directions with fixed seed offsets 741/947. The physical
direction is scaled to the registered radius; "suppression" denotes its
direction, not necessarily complete removal of that coordinate.

The exploratory family has 40 reserved comparisons (20 per backend): five
task contrasts versus native two-loop (single, calibrated, open, equal-compute,
bare), eleven phase/random edits, full donor, source-input, zero, and the
predeclared phase-identity activation diagnostic. All are reported, including
unavailable entries. Holm includes unavailable entries as p=1 for adjustment
accounting only; missing endpoints are never imputed as behavioral zeros.

## BPD instrument and causal gate

Start only at final-block o_proj/down_proj, ranks 8/16. Preserve frozen physical
operators plus explicitly measured residuals; for NF4 use dequantized effective
operators rather than the original BF16 matrix. Compare SVD/PCA, task-gradient,
delayed-Gramian, learned factors and rank-matched random bases. Any task-labelled
selection uses CAL only. Record preweight activations, writes, pass, position,
current-head effect, physical dose and source hashes. No full-network fitting.

CPU engineering checks cover native BPD full-product-plus-residual closure,
raw GL gauge fragility, canonical/group gauge stability, actual reached-state
routing, static masks and separately labelled clean-oracle routing. These are
finite engineering fixtures, never Nanbeige behavioral findings. Native trained
factors/gradient/Gramian fitting and primary donor transfer require the clean
competence and state-closure gates first. Blocked stages retain exact reasons.

The later fixed-arm family is clean, full donor, selected BPD, random-dark,
task-gradient, SVD/PCA, source-input, zero/ablation, and static vs reached-state
routing. The primary denominator includes all generated pairs; clean-loss,
zero doses and donor-target collisions are separate diagnostics, not exclusions.

## Reporting and scope

Use source-hashed model-only tapes and a separate oracle process. Freeze CAL
choices before DEV grading. Report all 40 predeclared exploratory comparisons
and two backend-specific proposed primary comparisons, with unrun ones marked
blocked. No root-symmetry or exchangeability assumption is silently asserted.
Do not claim equivalence from a null, unique semantic components from norms,
or donor-specific transfer from a logit displacement alone. Preserve previous
negative outcomes from CQ/SCM/ROC and original acceptance criteria.
