# NAN-MLP-27: conditional full-scope capacity fallback

This is a NEW native execution condition, frozen before its first pretrained
forward. FULL26 remains intact. Its actual supervisor and any surviving
model/host processes must terminate before this condition can start. No
CTX21, STORY23, FULL26 or math process is stopped or modified by this queue.

Qualification uses only closed, source-bound FULL26 resource receipts:
both backend receipts must be available, and at least one must report a
CUDA OutOfMemoryError or the exact registered input/A-B capacity-admission
AssertionError. Generic numerical, CPU-memory, source, package, time-budget
and correctness failures do not qualify this memory fallback. If neither
backend has a qualifying capacity failure, the stage is explicitly unrun.
If qualified, BOTH new precision conditions run fresh, including a matched
control even if that precision completed FULL26. No old neural response,
grade or orphan is replayed, adopted or repaired.

The entire ORIGINAL source26 scope is retained: 1,549 baseline contexts per
precision (GYM05 322, COMP14 240, CTX08 291, CTX21 624, STORY23 native 72), then
216 actual clean/intervention A/B pairs (all 24 story main worlds and all 48
focused competence worlds times component-only/static-CAL/reached-state).
Source order, prompt text, token bindings, bounded answer/trace parser,
generation budgets, EOS/first-packet stops, all controls and host labels
are exactly the frozen FULL26 ones. No case is chosen using model answers.
These are previously exposed development sources, not a new independent
competence cohort or a repair of the original algebraic/FIT07 gates.

The numerical change is an inference-only MLP workspace: gate/up projections
and their elementwise activation product are computed in 256-token slices.
Their full intermediate tensor is assembled and passed ONCE into the
physical down projection. The actual down-projection BPD hook therefore
retains complete token coordinates and one invocation per recurrent pass.
All 22 NF4 decoder layers and unchanged BF16 head remain on CUDA; BF16 retains
the same four layers plus stage and head. CPU embedding weights, exact GPU
token-embedding reuse, full-vocabulary greedy readout, native two-loop
recurrence and no-KV policy remain unchanged. No factor/dictionary refitting.

New gate/up GEMM shapes can change rounding. Before scored inference:

1. Compare original versus chunked B1 MLP execution on the fixed first CAL
   prompt, retaining all 40 relative/max differences and full-vocabulary
   logit/argmax differences. These differences are recorded, not used to
   filter tasks or select an accuracy-favorable setting. Reject nonfinite values.
2. Require exact chunked B1 old/new loop closure, full-head parity, B2
   clean/clean row identity, and B2 all-one BPD closure at every recorded
   physical state, boundary and full-vocabulary logit.
3. Probe these four distinct synthetic engineering shapes, in this order:
   B1x4608, B1x9216, B2x4608 with one right-padding position in row B,
   B2x9216 with one right-padding position in row B. Repeat the CAL token IDs
   to the designated length; no gold or task score is read. Every probe
   runs the actual reached-state controller, ensuring its allocations and
   the padded attention path are included. A B2 capacity pass cannot admit
   a B1 shape. An unpadded pass cannot admit padded B2 inference.
4. Require B1x9216 and padded B2x4608 to pass before ANY scored episode.
   This covers every registered prompt/token cap and every short A/B pair.
   A failed long B2 probe permits the separately tested long B1 baseline
   condition; there is no serial replacement for an A/B pair. Every OOM
   stays recorded. Distinct fixed preflight probes are not graded retries.

All40 actual last-valid-token vectors at every generated prefix, BF16 bit
storage, raw masks, native outputs at reached inputs, history/shape hashes
and readouts are produced by the unchanged source26 generation method.
The host inner grade/SAE/BPD numerical function is AST-identical to source26;
the new host initializes an empty append-only journal so zero admitted
episodes have explicit zero COVERAGE, not fabricated zero scores. Fixed
eight SAE dictionaries/random controls and both backend T2 fits retain their
original hash qualification and independent replay tolerances. Only exact
prompt/history/batch-shape prefixes enter physical cross-precision geometry;
means are taken within independent roots first. No fitted alignment.

The new namespace records completed captures separately from attempts,
including failed engineering captures. Cumulative CUDA allocator peaks are
not driver residency or a guarantee of capacity under different fragmentation.
Actual scored OOM stops that backend and all remaining contexts, with no
truncation, fallback retry, missing-output reconstruction or orphan rescue.
The original limits are retained: .90 CUDA fraction, four BF16 resident
layers, seven days of loaded-model time/backend, six hours/pair, 160 GiB state
artifact budget/backend, 20 GiB free-disk floor, unchanged token/character caps.
One model and one substantial CPU host analysis, one numerical thread each,
Below Normal priority. The separate math process is untouched. GPU and CPU
package versions are checked against ENVIRONMENT.json; no packages/models
are installed or downloaded. Large private artifacts stay on E:.

The supervisor captures the actual FULL26 handle immediately and waits for
it. If that metadata supervisor exits before children, their actual handles
are acquired and waited on too. After every source26 model writer has exited,
an absent model-lane-terminal marker can be closed as a registered
metadata-only handoff to release a surviving host reader. No neural data or
grade is synthesized. Missing closed source receipts leave this condition
unrun. Substantial old host work must exit before the new host starts.
The between-stage metadata wait is bounded at 30 days; upstreams are never
killed on observation timeout. Publication failures are logged without
stopping an otherwise valid resident model; sanitized milestones retry at
later registered report opportunities.

Prior exposure includes the original failures, COMP14/IO18/Prime20 results,
CTX21 NF4's 312 audited 4K contexts and first 8K capacity stop, source26 frozen
protocol/engineering, and CPU-only MLP27 fixtures. CTX21 BF16 is running;
STORY23 and FULL26 neural outcomes are not yet available at this freeze.
No original 168-case test is opened, including for exclusions. No new formal
inference, donor transfer, equivalence or causal confirmation. Meaningful
effect floors, dose-matched shams, independent-root power and a new untouched
confirmation readout remain uncalibrated: REDESIGN_OR_PILOT_ONLY. Finishing
this conditional finite stage does not pause or complete the continuous goal.
