# LOGRANK-BPD-16 development protocol
Fresh synthetic parity factor graphs; n=12,24,48; four independent roots per (n,family); families: disconnected blocks of four, overlapping consecutive triples (chain), random global triples (dense dependency graph, equal arity). Each world: two unary observations per coordinate and 3n triple observations, uniform hidden state, common per-observation noise uniforms at .15/.35. Eight distinct unobserved pair queries (four local, four random); all solvers receive identical observations. Compare weighted independent-factor bound from 15, component enumeration (component quotient rank cap 7; larger components fall back to independent-factor bounds), and mini-bucket max/min relaxation with maximum table scope 3,5,7 including eliminated variable. Fixed deterministic min-neighbor elimination and greedy grouping, one summed anchor per split; intersect bounds with the independent bound per conditioned partition weight. Report raw bounds too. For query parity, condition by eliminating its lowest-index coordinate through substitution; compute both event weights. Primary endpoints mean certified probability interval width and .9 posterior-confidence coverage. Secondary exactness, covered correctness, elapsed wall time, table slots, isolated-process peak RSS; uniform and exact references. Equal evidence, not equal compute. Exact independent check by exhaustive evaluation n12 and low-width frontier DP for block/chain at all dimensions. Random small fixtures and independent certificate replay for dense large graphs. No native model training, causal/confirmation claim, or protected cohorts. Worlds are independent units; conditions and queries within world are repeated measures. Fixed development comparison; no significance tests. Keep all results including failures. No branch-and-bound search here: this tests the replacement cell-bound kernel first.
