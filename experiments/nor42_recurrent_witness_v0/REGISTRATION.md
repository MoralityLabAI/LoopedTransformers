# NW-01: recurrent-model information boundary and authenticated-witness causal transfer

**First registration November 18, 2026, prior to any NW-01 model fitting or intervention scoring.** Original NOR42 source cohort and original grade are completed and public, so this experiment is an explicitly **retrospective model pilot on a previously published source set**, not a sealed prospective OOD result. The learned-model protocol is frozen before the first NW-01 training/evaluation. Every trained checkpoint, hidden-state trace and intervention arm will be recorded with a SHA receipt.

## Source and information-set contract

Use the source-first prospective [NOR42 paired-program audit](https://github.com/MoralityLabAI/Compactification-Theory/blob/0a330602c72ec34017178857956e306710f724a1/research/nor42_paired_program_ood/prospective/RESULTS.md), as archived at commit `0a330602c72ec34017178857956e306710f724a1`. The original public-only fixture has 9,059,929 bytes, SHA-256 `f8bc6ef3db4fda78709f2b7cd1a6a09989dbc087bcfb963d00961cc23ce4f033`, and original grade has 201,956 bytes, SHA-256 `bd57751d94ea49755888000675b0df8fce6490873683268b8f8625518701adae`. Their permanent original ZIP has 2,799,867 bytes SHA-256 `e60e97fd933f660c2274cb4a473ede7a98968d24eaf0dd3ae45ace1e1176cd0d`. That original NOR42 experiment and its independent 1,179,648-decision replay both passed, and **none** of those 64 source identities may enter NW-01 training.

Public-source unit: each of **64 NOR42 original public query/demo roots**, in 16 replicate blocks (100–115, four degree×family cells per block), has two possible equally likely truth labels, clean=0 and hidden=1. The same public feature vector must be used for both worlds. The true hidden residual at first changed coefficient D+32 is **β**, as recorded only in the original sealed grade and never available in any public-model-only feature. This is a synthetic **hypothetical authenticated output witness**, with no real-world cryptographic authenticity or entropy claim.

A fixed `features_from_source` function extracts public query coefficients and visible header/mask/density statistics, with deterministic clipping/normalization. It must read only `nor42_fixture.json` and never inspect the true label, hidden β, full private target, or result metrics. The original `nor42_full.json` supplies β **only** as the witnessed residual in the held-out authenticated arm. Negative controls preserve exactly the same paired public features.

## Model and split

Train a *small recurrent verifier*, sharing the structural motif of the repository's `research_gym.neural.trm.TRMProposer`: a public encoder, a witness encoder injected once at pass zero, a **single shared GRUCell** applied for eight recurrent passes, and a readout at every pass. The model is a binary candidate-correctness checker; it is not a full transformer, not a neural program induction result, and it is not BPD parameter decomposition.

Training uses **512 independently seeded synthetic public-source roots**, constructed from the same two declared input-density laws, with random original-program header and singleton native class indices but no original NOR42 test source identities. Each synthetic root appears in both equally likely truth worlds; hidden β is sampled from `{-2,-1,1,2}` independently of public features. Train the model simultaneously on paired public-only input `(witness_present=0,residual=0)` and paired authenticated input `(witness_present=1,residual=0 or β)`, always with equal balanced world labels. The witness feature includes the signed β/2 and its absolute magnitude/2. No world label or signed β is present in public inputs.

Run fixed model seeds **11, 23, 47**; train for **200 updates** each, batch **128 source roots**, latent width **48**, eight tied GRU passes, BCE on final readout, AdamW at **0.002**, weight decay **1e-4**. Use PyTorch CPU with thread count one and source seed **202611420201**. Freeze all hyperparameters, arms and root population before the first model run; no tuning on the original NOR42 source labels.

## Equal information comparisons and ablations

Every original NOR42 public source root is evaluated as a matched clean/hidden pair, at pass depths **1, 2, 4 and 8**, in three frozen information conditions:

1. **Public-only:** both worlds receive exactly the same public features, witness_present=0, residual=0. Their hidden states and logits must be identical at each pass within numerical `1e-7` (theoretical exact identity). Matched pair overall accuracy is exactly 50% regardless of classifier threshold. Source-mean Brier score against equal-prior truth has a theoretical floor of 0.25; report its excess above 0.25.
2. **Authenticated-residual:** both worlds share public features, with witness_present=1 and residual=0 (clean) or actual β (hidden). Score clean/hidden accuracy, Brier and depth-specific hidden-state separation. Evidence enters only at pass zero and is propagated by recurrent state.
3. **Sham-residual:** each public source has one deterministic residual drawn independently of its paired truth labels and presented identically to both worlds, with witness_present=1. Its matched pair accuracy is exactly 50%, even if a witness-trained model becomes confident. Report the sham Brier to expose overconfidence.

**Causal matched-pair interventions:** at passes 1, 2, 4 or 6, swap the full 48D hidden state between the clean and hidden *same-source* trajectories of the authenticated arm, then continue all remaining passes with the source-public recurrence input and no further oracle access. Compute donor-target final logit displacement, the signed/absolute effect, and whether the patched final logit equals its authentic donor's clean-run final logit. Register a separate **norm-matched random-direction sham** of identical state displacement and source-root dose, using seeded random orientation independent of truth and target. A same-world identity state patch is a zero-dose implementation check. State-swap is a causal full-state control and **does not establish a learned BPD fiber, component or basis**. No intervention parameters may be selected after seeing held-out NOR42 labels.

**Probe readouts:** report source-paired hidden-state L2 distances by recurrent pass for public-only, sham, authenticated. A post-hoc linear probe is optional and must be labeled observational unless split into separate fit/selection/held-out source groups; the registered causal endpoint is matched state-swap effect versus the norm-matched sham.

## Registered acceptance gates for this retrospective PILOT

- **G1 paired information firewall:** all 64 held-out roots share byte-identical public features across clean/hidden; public-only and sham hidden trajectories/logits are identical within `1e-7` at every registered depth, with exactly 50% paired accuracy and no original NOR42 train root reused.
- **G2 reachable witness signal:** final authenticated-residual accuracy at least **95%** and Brier ≤0.05 for at least two of three independent fixed model-training seeds, with root-level clean/hidden pairing preserved. Failure is recorded.
- **G3 recurrent retention:** at pass 8, authenticated same-source paired hidden-state distance exceeds 0.25 L2 on average for at least two of three seeds, and final clean/hidden logit probability separation exceeds 0.60 on average. This is limited to the input-injected synthetic witness information.
- **G4 donor-specific causal transport:** full-state opposite-world donor swap at pass 4 yields a mean final logit displacement at least **0.25 absolute**, greater than the norm-matched random-direction sham's mean absolute displacement by at least **0.10** for at least two seeds. Every donor patched final readout must equal the source-matched authentic donor final readout within `1e-5`; same-world identity patch must leave logits unchanged.
- **G5 integrity and EvalMath reporting:** per-source raw predictions and states, all three seeds, all depths and intervention arms are retained in first receipt; analysis groups 64 public root units into the original 16 replicate blocks, reports effects versus matched sham with descriptive 16-block uncertainty and multiple-arm caveats, and retains original frozen outcome booleans even on failure. Source SHA, grade SHA and exact training/feature implementation hash are included; the original NOR42 registered result is never presented as a neural confirmation.

## Scope and next stage

This is a **positive/negative information-access control**, not proof of authentic oracle availability, learned future truth, algorithmic reasoning or dark-fiber decomposition. It tests the mechanistic distinction between recurrent *belief confidence without identifying evidence* and recurrent **retention of an externally revealed coefficient**. A proper program-continuation experiment that trains a model to infer the clean RRC25 suffix, with new source-disjoint heldout pairs, is the next separate registration. BPD-specific decomposition requires interventions on named learned components and a stronger matched-support specificity test. The EvalMath gate treats 64 paired roots inside 16 generator blocks as 16 sensitivity units, with a minimum useful causal-effect floor of 0.10 in final-logit displacement over the sham.
