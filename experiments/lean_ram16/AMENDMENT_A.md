# RAM-16 preregistration amendment A: generalize source-header generator before data

Dated 2026-11-16. This amendment is registered **before any RAM-16 native source-macro collection, training, DEV score, or TEST source/goal access**. The original protocol at commit `4208074aa528c3e2b6b515b5b14b37642a9a340a` remains intact.

The verified RAM-14 grammar includes a prior-lemma matching threshold hardcoded to Gramian-specific identifiers `iterateState`, `transport`, `readout` and `StateGauge`. The unchanged original generator therefore cannot provide an informative broad curriculum across the already frozen TRAIN modules. The new RAM-16 generalization must retain every RAM-14 candidate on its original Gramian inputs and add generic, source-statement-only candidates as follows:

- **Typed Nat induction**: use the target statement's declared `n : Nat` or another visible Nat binder. Permit both `induction n generalizing x` for prior visible typed binders and `induction n` when a second parameter does not exist. Bound one-shot proof macros to `<;> simp_all [...]` and `<;> simp [...]` where the bracket entries are exact visible prior source definitions, earlier theorem names, or actual structure fields. No speculative declaration references.
- **Prior lemma matching**: gather previous original `theorem`/`lemma` headers (never proof bodies), require at least one shared nontrivial identifier from target/prior header other than keywords (`Nat`, `Int`, `Bool`, `Type`, `Prop`, `List`, `fun`, `true`, `false`, `theorem`, `lemma` and binder names), then select up to three in declaration order. Rewrites and simp use these names with deterministic fixed templates.
- **Prior definition matching**: select visible prior `def`/`abbrev` names that appear in the target statement, at most two. The target theorem's own proof body is discarded.
- **Family caps**: 16 concrete candidates each for `nat_induction`, `simp_prior` and `rewrite_prior`, at most 48 total. De-duplicate source scripts, record the source header SHA, full ordered candidate list, every namespace/lemma reference and its original declaration location. Scripts must match a fixed syntactic whitelist. All original RAM-14 grammar candidates remain unchanged on `GramianTransfer.transport_iterate` and `observable_transport`; preserve a regression unit test for their exact ordered candidates and old 4 triple-compiled proof hashes.

The training data gate and entire objective, 10/3/5 module split, 400-update 23-family recurrent/flat comparison, and untouched TEST source blobs are unchanged. Any failure of the expanded source-only generator must be recorded as a failed training-only run. Changes to this amendment after seeing compiler labels require another numbered, dated amendment and cannot be treated as an untouched original preregistration.
