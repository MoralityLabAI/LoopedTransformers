projecting each alternative onto the capped simplex for the learned

the baseline the same scalar budget information as the learned
controller.

per pass. Consider all 256 binary anchors plus the mean focused-CAL
last-token controller anchor and the published all-token CAL anchor.

local relative write error on the eight focused CAL roots, then
choose the lowest-error anchor. Break ties in the registered
enumeration order and freeze the choice before DEV evaluation.
Run both individual CAL anchors as diagnostic controls.
