# SELECT47 equal-budget selector verification

SELECT47 compiles finite DELAY39 device edges into six fixed-budget
Nanbeige selectors. Every selector receives three phase-1 write
components and four phase-2 observer components. It compares the
path sieve with local degree, weighted degree, complete-graph
attribution, isolated signed-dose response and fixed-bank activity.
Both worlds of each calibration root contribute equally. A precision
needs at least six complete roots before it can issue a mask.

The source-mask identity is the relevant GPU deduplication key. If two
selectors use the same three write directions, they share the edit
and the post-rounding dose test on a fixed prompt. Different receiver
lists can use the same second-pass tensor. This follows the equal-budget
and exact-mask logic of the original E10 study.
[PercInterp E10](https://github.com/MoralityLabAI/percolation-interp/blob/ae871eac4a95d787b980dad0abd5a60d9140b4e4/docs/e10_decisive_gate.md)

The four-stage fixture produced a distinct sieve and degree source
mask under the same budget. The six methods reduced to three distinct
physical source edits, including a receiver-only difference that shared
a source edit. Exhaustive enumeration matched the bottleneck dynamic
program. A signed cancellation fixture retained two paths and their
zero signed sum. The terminal compiler refused a changed hashed
episode, kept three dose-incomplete worlds outside the complete-root
pool, and abstained with five complete paired roots. A simulated native
failure produced zero masks.

This test issues real masks only from the authenticated DELAY39
terminal, source, qualification, and closed-journal receipts on the
device artifact volume. It keeps zeros and incomplete doses visible,
and the expected graph is built on the fixed IO18 factor identities.
The actual delayed edges and prospective matched causal outcomes
remain pending. The CPU check used no new pretrained forwards
and no sealed ARG-03 data.
