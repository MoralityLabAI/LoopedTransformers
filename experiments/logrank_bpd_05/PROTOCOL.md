Fresh seeds 1103/1201 at k=16 and 1301/1409 at k=32. Four arms: flat assignment, greedy hierarchical assignment, hierarchical rank-16 factorized head, fixed query. Width 32, 500 Adam steps, batch 128, lr .003, lambda .5. Fixed schedule q Bob bits plus one Alice reply. Disjoint 1024 memory vectors per split, test first 256 from each across all k query coordinates. Report bit accuracy, exact-row accuracy, code coverage, uniform-distribution collision ceiling, path positions and timing. Sample accuracy is not a certified uniform-domain bound. Equal allocated parameters, unequal work; fixed-query oracle is a structural control. No native BPD trainer, no causal or confirmation claim; factorization is a proxy. All planned outcomes retained; root matrices are indexing isomorphisms. No protected data.
