# LOGRANK-BPD-11 development protocol
24 fresh worlds (six each k=16,32 and r=8,12); eight scale-only worlds (four each k=64 r=24,48). Independent even parity basis of rank r+3, uniform hidden signs. 32 disjoint non-singleton coefficient test masks. Schedules start with r independent rows, then repeat basis, sparse random weight 2/3 rows, or dense random nonzero rows (large-scale: repeat and sparse only). Nested budgets 2r,4r,8r,16r,32r; known independent noise 0,.15,.35 (large-scale .15,.35), common noise uniforms. Exact small-r posterior versus damped sum-product (60 iterations; combine repeated factor LLRs; independent marginal products for parity predictions). Record block correctness, query accuracy, Brier, coverage, solve time. Rank expansion: from dense 4r, three calls within span or one each along three new independent directions, random offset versus maximum expected Brier gain on 24 public out-of-span targets (no direct target calls). Fresh generator worlds; development only, no native BPD or protected data.
