# NAN COMP 02 fresh source competence pilot

This new development condition addresses NAN-BPD-01's failed behavioral gate.
It does not change that study, its acceptance criteria or the original ARG-03
168-case test. Do not read, regenerate, or use the protected test for exclusions.
No BPD transfer or dictionary fitting is enabled in this pilot.

## Task and source construction

Identify a SINGLE unary operator I, N, S or R from two input/output series,
showing only coefficients through degree four. The frozen EvalMath unary
oracle generates fresh polynomial demonstrations and a hidden degree-32 query
future. A separately implemented finite geometric inverse/convolution checker
must verify every source and tutorial output. The four operators must be
unambiguously distinguished by the public examples. This is a finite exact
certificate and a structural solver ceiling, not a neural mechanism finding.

Two separate CAL roots and eight new DEV roots each contain two counterfactual
worlds. A pair shares inputs/query/family and differs in the verified operator
and query future. Clean prompt token lengths match within pairs. Erasing the
task outputs gives exactly identical token IDs across a pair. Construction
uses only sources and tokenizer lengths; retain all rejection counters and
all admitted worlds. Never replace a world based on checkpoint behavior.
DEV operators are balanced: four worlds per operator. Source/world IDs,
family, split, target operator and hidden futures are never rendered.

## Fixed formats and decoding

Direct and worked-example formats are fixed in prompt.py before inference.
The worked tutorial covers all four operators equally on a separate elementary
source. The null uses the same worked tutorial but redacts current task outputs.
Use the checkpoint's native chat template with thinking disabled, followed by
the assistant prefix `Operator:`. No format is selected from CAL or DEV results.
CAL is reported separately; no temperature fitting or parameter training occurs.

Arms: direct loop one/two; worked loop one/two; output-erased worked loop two.
The erased prompt is independently evaluated twice per root (original and
repeat sham), each reused for the pair's identical inputs, with reuse recorded.
All other model forwards use one source prompt
at a time, and the native two loops without embedding reinjection.

The FULL vocabulary determines the greedy first token. Bare and space-prefixed
single-token spellings of each operator are accepted aliases, frozen from the
tokenizer before models run. A different first token is a format failure.
Also report four-way alias-marginalized ranking and full-vocabulary grammar
probability mass, keeping these distinct from unconstrained greedy correctness.
Every accepted predicted operator must verify both public demonstrations and
the hidden degree-32 future in the separate oracle process.

With four candidates, verified search@12 is an automatic 100% source ceiling.
It cannot establish competence and is not the gate. This explicitly new task
does not pass or rewrite the old compound-program gate.

## Development competence gate

The main arm is worked native two-loop. In EACH backend require at least 12/16
unconstrained greedy, verified future-correct worlds; at least 6/8 roots with
BOTH distinct targets correct; and at least 0.25 mean paired accuracy advantage
over output erasure. Both-pair correctness is impossible for any input-blind
constant predictor, including the identical erased inputs. Restricted four-way
accuracy alone cannot pass. A joint BF16/NF4 gate requires both backends.

A pass licenses design of a separately registered BPD pilot on this unary
condition with new sources. It is not transfer, causal mediation, confirmation,
equivalence, or competence on the original 64-program task. A failure is kept;
no new prompt or case search is performed in this readout.

## Comparison family and statistical resolution

Unit: independent generator root. Two worlds, formats, depths and backends
within a root are correlated. There is one pretrained checkpoint. Primary
within-backend source-use contrast: worked loop two minus output-erased loop
two. Scientific minimum: 0.25 solve fraction. No hidden-state dose applies;
the intervention is source-output erasure. Two CAL roots are separate from DEV.

Nine comparisons are frozen: in each backend worked2 versus erased2, worked2
versus direct2, worked2 versus worked1, and worked2 versus a uniform-label-prior
constant I baseline; plus NF4 versus BF16 worked2. FSI-01 provides root-macro
effects, cluster bootstrap descriptions and exact conditional root sign flips;
Holm includes all nine. Paired-label exchangeability is unestablished: withhold
unconditional inferential p-values and keep sign flips conditional. Zero-effect
roots remain in all counts. No generalization or superiority confirmation.

Run the strict mechanistic-power planner before compute using no invented
empirical calibration, then again on actual DEV-root source-use effects.
The repeat-sham effect compares the original and repeated erased predictions
on the SAME labels, then averages over the two worlds within each root. The
labels differ across worlds; identical predictions do not imply identical
per-world correctness. Record actual repeated scores/argmax differences and
do not replace them with assumed zeros. This tests numerical/format repeat
noise under identical inputs, not all semantic source-intervention variation.
It is a limited format/source sham, not a calibrated 95th
percentile causal-intervention floor. Eight roots cannot supply the 59 sham
worlds required for a 95%/95% sample-maximum bound. A 60-root later plan is
provisional, not a power guarantee. This entire readout is development-only.
