# ROUTE58 native runner and independent scoring

The independent host reads the source-bound gold packet and records twelve
root-level native competence decisions before assigning any edited world.
The model runner replays registered public IDs against the pinned tokenizer.
The model runner only receives the competence receipt, the decoded native
labels and public sources. It checks duplicate clean rows against the
original matched B2 row by fingerprinting both passes' vocabulary heads,
residuals, projection inputs and module writes.

For qualified roots the existing SHAM56 live minimax policy preflights all
four signed current heads before issuing any edited continuation. Each
live first-pass head must equal its approved tensor. The worker records
first-pass RMS drift and signed bare-margin shift, along with the actual
realized dose and second-pass BPD read, bare margin and greedy token. The
independent scorer reconstructs the nominal-dose normalized signed
contrast-minus-sham from these records. It checks head telemetry, gate
eligibility, root assignment and journal hashes. It aggregates only
complete A/B roots and retains counts of all 24 world slots. The 0.125
relevance threshold is descriptive. Future sham variation is uncalibrated.

Admission uses the existing exclusive GPU lane, waits for integrity-closed
predecessors including DELAY39, checks the pinned adapter and publication,
and requires the two-depth CUDA preflight. Normal checkpoint target,
quantization state and artifact closure are required after the run.
The CPU verification fixture exercises the real staged tiny decoder,
a multi-block synthetic head, registry qualification, finite scoring and
malformed receipt refusals. This is runtime engineering evidence. The
pretrained CUDA run, future effects, and causal conclusion remain pending.
