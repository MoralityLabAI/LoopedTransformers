per precision. The independent query oracle checked all 16 focused
worlds, and every paired prompt had the same token length. The fixed
tokenizer found a maximum prompt length of 389 tokens.

caches, a staged layer, streamed vocabulary head and the production
boundary hook. Across 17 edited examples it produced seven signed
cross-pass edge rows, eight qualifying phase-2 sink checks, and two
matched shams. Full-tensor reference logits agreed exactly. The
phase-1 projection input stayed exact, the phase-2 projection input
changed, and a stale patch was rejected. A clean capture after the
rejection remained exact. Peak sampled private memory was about
655 MiB, with at least 7.08 GiB host RAM available.

gate, missing paired outcomes, and four-stage PercInterp controls.

and a disconnected fixture gave a strict difference between local
in/out membership and complete path membership. Both are synthetic
structural checks.
