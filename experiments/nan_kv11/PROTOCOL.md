# NAN-KV-11: native cached/full-prefix execution across the public wider suite

Freeze and push every source before pretrained execution. No changes to any
earlier scientific worker or dataset. Use the existing verified checkpoint,
same native full-stack two-loop arithmetic and unchanged resident BF16 head.
This is a numerical execution condition, not a new competence or causal study.

## Complete roster and forced natural histories

All 130 public GYM05 DEV contexts from 41 source families, without outcome
selection: pointer 80, ARC1 6, ARC2 6, Sudoku 6, storyworld 32, including all
public copy controls. Private routing text is excluded from this public-scope
engineering condition, not relabelled as absent from prior suite results.
All previous outcomes are exposed. No independent replication is claimed.
No host gold or grading module is imported by the model worker. The original
168-case ARG-03 test is never read, regenerated or used as an exclusion set.

For each source, run the uncached native reference first, then the cached path
on exactly the same token history. At step zero both execute the full prefix.
Subsequent inputs append the reference's free full-vocabulary greedy token,
including when the cache argmax differs. Stop at reference EOS or eight total
token readouts. Preserve every disagreement; never rerun or select a more
favorable history. Cache argmaxes on reference histories do not establish the
cache's independent free-running reply after a divergence. These short fragments
are not complete Sudoku/ARC/plan benchmarks and receive no task-accuracy score.

Reset both pass caches for each source. Use independent DynamicCache instances,
correct positions/causal masks and the physical logical layer index, including
the reusable BF16 stage. Keep loop_idx=0 per native pass as in the existing
backend. The experiment still has two loops; future-correct@12 in the original
campaign concerns its search/readout contract, not twelve recurrent passes.

## Parity, observability and controls

Before DEV, one fixed CAL source warms both paths and checks all vocabulary
logits/scorer fields of CPU versus unchanged resident head at both loops.
No model-outcome gate selects this source. Every DEV initial cached prefill
must exactly match reference boundaries, all vocabulary logits and all forty
physical vectors at layers 5/11/17/21 and both loops. Stop that backend on
prefill failure; retain the failed source and missing coverage. Do not retry
with different precision, chunks or algorithms.

For each measured step, archive paired full-vocabulary logits, normalized
boundaries and all raw physical residual/down_proj/o_proj input/output vectors.
Compare incremental errors and every argmax without threshold tuning or a
claim of drop-in equivalence. Record token histories, EOS/truncation, cache
length/bytes and model parameter hashes before/after. The expected BF16 K/V
storage is 180224 bytes per cached token across both passes/all 22 layers.
The CPU audit recomputes every archived paired difference and source binding.

The random native 22-layer/width-64 fixture passed FP32, BF16 and NF4 checks,
with bit-exact prefills and both aligned/un-aligned MLP variants preserved.
It is separate engineering evidence. NF4's incremental single-token kernel
changes can produce nonzero state/logit differences despite matching argmaxes;
the real run measures these rather than assuming numerical identity.

## Resources and reporting

NF4 then BF16, one large model at a time, after the actual PRIME-CTX10 amended
supervisor/model/learned-factor probe exits. Keep one numerical CPU thread,
Below Normal priority and .85 CUDA fraction. NF4 all decoder layers/head on
CUDA; BF16 four layers plus reusable stage/head. CPU embedding lookup remains.
The existing loader verifies locked weight/code hashes; no downloads/upgrades.

Backend budget 7200 seconds including load/warmup, checked between measured
steps. Preserve finite in-flight work. OOM, budget, parity, I/O and other failures
remain terminal partial conditions; no automatic neural retries. Progress uses
append-only events, never a live atomically replaced progress JSON. Audits read
closed records or terminal artifacts, never rewrite model output. Raw vectors,
tokens and readouts stay local; publish named aggregate reports/hashes only.

Timed paths include both-loop probes/full-vocabulary readout, exclude archive
compression, use CUDA synchronization and fixed reference-then-cache order.
Report shared-machine contention/order/warmup limits, not isolated throughput.
Measure CUDA allocated/reserved peaks; driver dedicated/shared samples remain
separate metadata and are not inferred from tensor.device alone.

Unit: 41 heterogeneous source families, 130 contexts, one checkpoint. Token
