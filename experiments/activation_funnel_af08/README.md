# AF-08: qualified-checkpoint noncollapsing proof-state locality

This new experiment addresses the AF-07 failure in which a nearly fixed compressed Q representation had only chance-level subgoal semantics. It starts directly from two independently qualified AF-06 warm-up checkpoints, **seeds 17 and 29, width 2**, which had 1.000 goal and exact joint Q accuracy on both original training and development. AF-08 does not repeat, overwrite, or relabel the AF-06 training run.

## Scientific design

The parent AF-05 gym exposes initial leaf facts and public rule incidence. The original native TypedLoop infers two intermediate subgoals Q0/Q1, and the downstream stage must carry those variables to G without upstream evidence. An addressed code interchange replaces one atom's actual carried Q code with a matching donor. An independent least-Horn-fixed-point oracle produces the counterfactual Q and goal outcomes.

All three arms start from identical frozen AF-06 warmup weights and execute the same number of cell calls per continuation step. The `status` arm receives the unrelated-Q patch and semantic labels. The `locality` arm receives a gradual addressed-patch curriculum, semantic supervision, and a per-step KL/code-displacement locality penalty for the untouched Q. The `noncollapse` arm shares the same exposures and adds a pair of explicit discriminative margins to keep opposite Q statuses and changed-status patches distinguishable in the carried code. All arms have the same lightweight warm-up weight anchor. Loss arithmetic and backward FLOPs are not fully compute-matched.

A successful code-distance regularizer alone can admit a constant code. The noncollapse losses penalize that collapse, while exact supervised Q CE and clean-accuracy gates require those separated codes to be semantically useful.

The complete scientific registration is [PROTOCOL.json](PROTOCOL.json). Its source, cutoffs, original AF-06 ZIP digests, train/dev-only training access, and failure policy were frozen before the full run. See [AF-06 results](../../docs/research/AF06_RESULTS.md) and [AF-07 results](../../docs/research/AF07_RESULTS.md) for the immutable parent outcomes.

## Reproduction

CPU Python 3.12, Torch 2.5.1+cpu, NumPy and SciPy. Download the two exact artifact ZIPs from AF-06 GitHub Actions run `43599882702`. Each is verified against a pinned SHA-256 and full AF-06 training manifest including source, checkpoint and `.npz` tensors.

```bash
python -m unittest discover -s experiments/activation_funnel_af08/tests -p 'test_*.py' -v
python -O -m unittest discover -s experiments/activation_funnel_af08/tests -p 'test_*.py' -v
python -m experiments.activation_funnel_af08.experiment source --seed 17 --source-zip /path/to/af06-train-s17-w2.zip --out /tmp/source17.json
python -m experiments.activation_funnel_af08.experiment train --seed 17 --source-zip /path/to/af06-train-s17-w2.zip --out /tmp/af08/train17
python -m experiments.activation_funnel_af08.experiment evaluate --seed 17 --training /tmp/af08/train17 --out /tmp/af08/eval17
python -m experiments.activation_funnel_af08.verify --seed 17 --training /tmp/af08/train17 --evaluation /tmp/af08/eval17 --out /tmp/af08/eval17/independent_audit.json
```

The final CI matrix contains two seed-specific jobs for training and two separate evaluations, plus source/Lean preflight and a registered cross-seed aggregate. Qualifying on training/development is required before a held-out scientific positive claim. Every ineligible seed and negative result remains in the saved raw logits.

A checked Boolean theorem in Lean certifies only the independent finite Horn oracle, not a proof generated by the neural model. Any extra five-step downstream evaluation is a tensor-only extrapolation and receives no original Lean proof credit.

### Engineering correction to frozen scientific source

The initial training execution at source `bbfd96b` produced a nonfinite loss in the `noncollapse` arm. The culprit was differentiating the mathematically registered Euclidean norm through a zero-distance code collision with `sqrt(sum(square))`, which has an undefined derivative at zero. The repaired implementation uses `torch.linalg.vector_norm` (same Euclidean norm forward values, with a defined zero subgradient at the singularity), adds an exact collision regression and halts on nonfinite losses, gradients or model weights. The registered oracle, loss coefficients, margins, comparisons and eligibility thresholds remain unchanged. The failed initial execution is retained as an engineering incident; valid full scientific scores require a new source-pinned CI run.
