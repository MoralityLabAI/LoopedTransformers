# AUX-V2-MMS-01: physical factor replay and causal counterfactuals

Engineering candidate. The prior AUX-GYM V2 CPU CI passed (run 45825486131, head 7e0e54a4). This extension is development-only until its tests run.

## Physical factor convention

The existing BPD implementation (MoralityLabAI/BPD, mechinterp/bpd/components.py) shares a physical V,U pair across invocations and initializes from an SVD. Here the tied decoder's actual MLP down-projection W is left dense. A detached top-rank output basis Q is refreshed from W's SVD every 100 updates. The native forward hook reads its answer-position write once per visit. For a current exact SVD, projection of Wx onto Q is the top singular component readout. Stored past writes are ambient vectors; reprojecting them avoids stale sign/permutation coordinates, though representation drift remains.

This is deliberately a physical-weight SVD proxy. Native BPD's behavioral faithfulness/minimality/adversarial optimizer, multi-site interventions, pass-neutral ablation, factor-identity alignment and tolerance calibration remain to be integrated. The proxy does not establish learned BPD mechanisms.

For a current write q and same-depth/visit donor writes p,n (same symbolic state and next cyclic state class), optimize softplus(4*(cos(Q^T q,Q^T n)-cos(Q^T q,Q^T p))) over admitted pairs. Donors and basis are detached; only current native write receives gradients. The loss is averaged over the full batch and eight visits, including zero contributions from missing donors. Log admission coverage. Base loss is final CE + symbolic visit supervision in every arm. Each training root uses the same task sampler, seed, fixed steps and eight visits; map sampling uses a separate RNG. No locked labels enter training.

The CPU bank allocates fixed float32 vectors, counts and cursors per depth/visit/class; FIFO, no full-bank scans. With K=4, a hit gathers four prior donor vectors with replacement. RAM cap covers persistent tensor allocation, not Python/PyTorch allocator overhead or model memory. RSS and wall time are reported separately (RSS unavailable on Windows with this implementation). 0 MiB is off or within-batch control; memory tiers 4/16/64 MiB with actual allocation and occupancy recorded. With 128-dimensional writes and 9*8*17 buckets, the bank holds approximately 6/26/107 vectors per key. A random orthonormal basis and shuffled memory labels are the negative controls. Shuffled labels roll within the minibatch; cross-depth label distribution and donor admission can differ, so report coverage, add within-depth label permutation for confirmation. Zero-tier controls use different donor availability; compare memory against both and stratify coverage. Fixed optimizer steps and rank do not imply exact FLOP equality; measure training time, overhead, profiler FLOPs and peak memory. CPU lookup and transfer overhead are included in training wall time. The design does not claim a speedup.

## Counterfactuals

The builder creates changed-terminal and full-trace-preserving control pairs at each depth from existing V2 anchor examples. A modular edit replaces one operation; a masked edit exchanges two destinations (including hole relocation). Re-solve the complete trace with both the native solver and independent oracle. Keep V0 hash-region ownership, V2 split-group disjointness, unique new donor fingerprints, and familiar/one-novel modular regimes. Fail rather than silently underfill. Source anchors may recur in different pair types; statistical inference is clustered by model root and anchor. Same-target controls need not match edit kind or divergence distribution; collect edit-stratified dose-matched controls before confirmation. Anchor datasets and generated pair labels are available to the offline builder; training never reads them.

The evaluator intervenes at the first divergent operation's visit (or terminal visit for same-trace control), adds the donor-minus-anchor answer-position MLP write projected into the rank-r physical output subspace, and continues the actual model. The random within-subspace sham has the same write norm; the clean anchor/donor and both interventions are saved. Restrict primary causal hit-rate to pairs both solved cleanly; disclose all counts and treat zero admitted pairs as inconclusive. Depths exceeding the chosen visit budget are explicitly excluded from intervention, and extra visits are a separate tied-only diagnostic. This is teacher-informed intervention, not evidence of autonomous prediction or proof of mediation. Same-target preservation and raw donor-margin shift are secondary.
