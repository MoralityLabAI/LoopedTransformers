Compare direct, LRU, planned cold, warm marginal greedy (21), resident-aware greedy, and retention-aware greedy at 16/64 KiB (11 arms). Retention greedy minimizes current work plus expected next work, using current public demand as next-demand forecast, same target set, and post-fill residence minus messages invalidated by hypothetical next owner. Local uses known site, uniform uses four fixed independently sampled public scenarios (not actual future updates); final epoch current-only. Both greedies use all feasible candidates, exact integer ratio comparisons, no future observations/queries. Primary 96D hub 16/64 KiB comparisons versus warm marginal and planned cold; all factorial regimes retained, paired root is independent unit, descriptive only. Measure counted arithmetic, actual elapsed including planning, cache transitions, no process RAM guarantee. Sequential rotated arm order.
