# GATED46 precontinuation qualification

GATED46 registers the native follow-up to the 0.25% SPECTRAL45 head
calibration. Eight new COMP14-format pointer roots supply 48 paired
prompts across focused, literal-copy and graph-erased arms. An
independent source parser and oracle replayed all 16 focused answers,
and the pinned tokenizer confirmed matched twin lengths and exact
erased-input identity. The longest prompt has 389 tokens.

For each independently qualified root-world, the worker prepares four
edits: positive and negative margin-null donor and dose-matched span
sham. The full native head must agree at the current readout for all
four plans. The edited B2 worker checks the actual full-vocabulary
boundary against the approved plan after pass 1, then continues through
pass 2. The host scorer verifies the journal and computes the signed
sham-adjusted future margin, both-world coverage, exact recipient
accuracy and donor flips.

The CPU commissioning fixture used a staged BF16 layer, independent
DynamicCache phases and the real streamed vocabulary head. It ran the
four accepted signed edits and independently scored them. An invalid
plan and a forged plan with a valid-sized but unequal boundary each
caused zero edited second-pass decoder calls. Native replay recovered
exactly afterward. A deliberately refused four-arm group also reached
zero edited second-pass calls. The synthetic physical radius exercised
the fixture's BF16 rounding, and SPECTRAL45 provides the archived
Nanbeige evidence for the registered 0.25% radius.

The independent host native qualification subprocess accepted all
48 constructed source decisions and rejected a literal-copy failure.
A separate terminal fixture scored one complete synthetic two-world
root, retained 14 unsupported worlds, returned 16 unknowns on native
refusal, and rejected a changed episode file. A cold device admission
check refused the live RAM28 worker before importing Torch or
creating an artifact. The CPU test used 655.0 MiB maximum sampled
private commitment and 397.0 MiB working set.

The local freeze binds the worker and its receipts. CUDA, publication
and the native measurements remain pending. The registered GPU entry
point is:

```powershell
python -B -m experiments.nan_gated46.worker --backend nf4 --snapshot <checkpoint> --adapter <adapter> --source-dir runs/nan_gated46/source
```

Run staged BF16 after the NF4 process exits. After a backend closes,
run its independent CPU scorer:

```powershell
python -B -m experiments.nan_gated46.host --source-dir runs/nan_gated46/source --artifact-dir <closed-backend-directory> --output <local-aggregate>
```
