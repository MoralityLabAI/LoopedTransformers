## Fresh strenuous world tasks

The user requests storyworlds with reasoning traces combined with BPD tracing
and SAE towers, keeping the4-GB3050 productively occupied. Generate12 independent
source worlds:one CAL and three DEV roots for each of physical object tracking,
first-order recorded belief and second-order recorded belief. Every root has
two counterfactual stories differing in one event destination and with distinct
final correct room labels. CAL stories have96 events; DEV stories have32/64/96
events per query family. Nested containment, public handoffs, private movement
and partially observed event feeds require temporal updates and multi-hop paths.

All initial locations are common knowledge. Only listed feed viewers see an
event and who else sees it; the acting person always observes their action.
Each viewer updates its own parent map. A's map of B's belief updates only
when both A and B observe. Unseen events leave records unchanged. This is a
fully specified finite belief-record simulator, not an unrestricted human
epistemology claim. Private later events deliberately separate actual location,
first-order belief and second-order belief at the queried final time.

Generated traces must state the queried room at three prespecified intermediate
times, give the current evidence/containment path, and give the final room with
an explicit END marker. Grade final correctness, all intermediate states,
path correctness and joint trace correctness separately. These are observable,
checkable model explanations; oracle-consistent text does not prove internal
reasoning faithfulness or causal mediation. The whole-reply parser is anchored,
bounded and source-locked, with no prose scan or answer rescue. Canonical gold
trace token counts must fit the declared64-token budget before inference.

Native main/copy/whole-story-erased arms cover all24 counterfactual source cases.
Erased A/B prompts are byte-identical and retain distinct answers; use fresh
independent forwards for both, not cached replies. Copy controls retain the
story and explicitly supply the entire verified trace. Their exposure is
intentional. Synthetic sources and host labels are public frozen fixtures;
the model server never reads the host grading map.
