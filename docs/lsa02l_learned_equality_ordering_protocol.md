# LSA-02L: learned equality-search ordering

Status: registered development experiment, before fitting or opening its fresh development roster for evaluation. CPU/RAM only. Parent: LSA-02K, PR #334, merge a72496b77754cf4e63904ff8595b9729fbec1c22.

## Question

Can a compact weight-tied recurrent distance estimator reduce public rewrite-graph search costs on unfamiliar equation systems, while every claimed closure remains native Lean certified? The unrestricted bidirectional planner is a ceiling. Compare the learned ordering against strong inexpensive public bounds, not merely random or local DFS.

## Model and controls

Canonicalize the public equation set and the theorem endpoints under the 24 symbol permutations, equation orientation and equation ordering. Resolve residual automorphisms by the least transformed current word. Encode the current word, witness word and six equations in 196 one-hot dimensions. No root IDs, lineage IDs, reference paths or distances in features. The 48-wide network has an input projection, one shared 48-by-48 residual-injected recurrent update, and a scalar nonnegative distance readout. Unroll four updates; the single-update architecture ablation has exactly the same trainable parameters. Use AdamW, learning rate 0.003, batch 64, 30 epochs, seeds 107 and 109, CPU one thread. Loss is smooth-L1 distance regression plus listwise cross entropy over the recorded successor among legal distinct successor words. Terminal reference states train only the distance readout. Train each arm twice independently on the same worker and require identical state-tensor digests. The sham uses within-state randomized positive successor indices and shuffles distance labels within word-length strata, with the same optimizer, seed, data and architecture. Retain checkpoint hashes and state tensors.

## Search

Use a shared heap-based graph search, duplicate suppression with reopening for improved path length, a 15-rewrite path limit, and goal-on-pop. Order by g + predicted distance for both learned and sham, and use the same deterministic Hamming/word tie-break. Exact endpoint equality has zero heuristic. Public comparators: original bidirectional BFS; Hamming greedy; Hamming A* with ceil(Hamming/2); edit-distance A* with ceil(Levenshtein/2); positional symbol-relaxation A*; adjacent-pair projection A*. The positional bound is the maximum of individual shortest letter distances and ceil(sum/2), using position-appropriate relaxed transitions. The pair bound is max of individual projected shortest distances and ceil(sum/3), since a rewrite touches at most three adjacent-pair windows; allow boundary-crossing rewrites with unconstrained outside letters. Combine it with the positional bound. Count abstract-table setup expansions and edges separately, including setup time in planner wall time. This gives classical projection search its setup work for free in the primary full-word expansion comparison, a deliberately conservative control.

Run each arm independently at full-word expansion caps 16/64/256/1024. Count all enumerated public moves (including duplicates), frontier/model states scored, model batches, inference time, planning wall time (including encoding/table setup), proof tactics and native verification time. Report edge thresholds 128/512/2048/8192 using the deterministic max-cap trace; these are retrospective threshold receipts, not separately timed edge-limited executions. Report joint expansion+tactic caps as illustrative accounting only. Run the exact public planner at its original ceiling. Every proposed closure must be replayed against the native Lean state and independently compiled with no extra axioms. Deduplicate identical proof paths for physical native work but charge each algorithm its own logical proof tactics. Search failures have zero native tactics. No planner may receive the reference path or exact distance at evaluation time.

## Frozen decision rule

Primary endpoint: certified root closure at 64 full-word expansions. Aggregate learned, sham and single-step arms across the two seeds within each root. A developmental signal requires learned minus strongest aggregate public baseline >= 0.125 (four of 32 root equivalents), a root-paired 95% bootstrap lower bound > 0 using the max public baseline in each bootstrap sample, learned minus sham >= 0.0625, and learned superiority over the sham in both seeds. Report comparisons to single-step; recurrence-specific attribution additionally requires superiority over it. Report all four caps, edge thresholds, depth and wall-clock costs, failure cases, per-root and per-seed receipts. Exact planner closure is a ceiling. This gate is a developmental signal only; a compute-advantage claim further requires measured total planning cost improvement, and architecture promotion requires an independent preregistered sealed confirmation. Failed gates and negative results must be archived. No further architecture choice or parameter adjustment is authorized by this experiment.

Engineering tests must verify projected bounds against exact small-graph distances, canonicalization under renaming, cap/path invariants and the existing native grammar. Native CI must pass before any scientific result is stated.
