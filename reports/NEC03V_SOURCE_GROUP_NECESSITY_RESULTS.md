## Registered experiment

The original source-trained native teachers have 12 shared-weight recurrent visits. Each original 128-feature TopK16 SAE produced a frozen, nonhub 32D decoder subspace. Source-fit coactivation and masked physical decoder geometry selected a connected four-code group and a disjoint active four-code structural sham. The same source-fit rule was frozen before scoring either removal. Both removals had the same nonamplifying local physical norm at each selected visit.

Only source-training groups 24..31 were scored, with 32 original focal masks per group, making 256 source cases per teacher arm per historical root. All eight original world roots dev5-000..007 were present, and original roots 3 and 5 were fixed to zero for the original intention-to-treat primary. No recruited, reserved, embargoed or four-input confirmation world was opened.

Single root effect:

    D_r = [(composed_sham_correct - composed_group_correct)
           - (additive_sham_correct - additive_group_correct)] / 256.

Primary = average D_r across all eight original roots, with roots 3 and 5 set to zero. Original meaningful positive-effect floor = +2 percentage points. No source-training result can serve as population confirmation.

Previously authenticated original source-physical four-feature feasibility was **1,526 / 1,536 = 99.35%** paired cases across the six originally source-eligible worlds. Physical admission used the predeclared >=95% case coverage, >=0.1 shared 32D dose, >=80% source/sham directional cosine <=0.95, and <=1% physical-dose mismatch, based only on historical source-fit features. Invalid cases stayed paired zero perturbations in their 256-case denominator.

## Decision

**Retire the current strongest-coactivation four-code group necessity endpoint as the candidate for NEC03P population confirmation.** The previous n-code necessity variant had a negligible source correctness contrast, and this newly designed four-code variant has a negative registered source-only contrast despite strong physical sham matching. The frozen original source experiment is an informative **negative result for the tested mechanism**.

The result does not establish that neuron communities are generally unnecessary. A future independently preregistered mechanism would need a different source-only causal design, for example joint functional-dependency groups, a matched decoder-subspace rescue intervention, or a complementarity-based group selection criterion, with explicit new matched controls and falsifiable success gates. No such new design is authorized by this report.

The original NEC03P recruited cohort has 88 roots, of which 69 remain source-eligible and **zero have new NEC03V causal-sham outcomes**. All reserved, 32 five-input embargoed and original 64 four-input confirmation cohorts remain sealed. The proposed >=59 independent eligible root 95/95 tolerance experiment remains suspended. FSI-01 stays REDESIGN_OR_PILOT_ONLY.
