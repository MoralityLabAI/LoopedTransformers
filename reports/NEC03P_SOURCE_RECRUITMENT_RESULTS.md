# NEC-03P: 88-root prospective source-only recruitment

**Completed 21 November 2026.** The original code, complete 88-root cohort and analysis plan were preregistered at [commit `a80c1a2`](https://github.com/MoralityLabAI/LoopedTransformers/commit/a80c1a2c59fb7f85c7b496056ddd66173bdcdf6a) before any new native model run. [GitHub Actions source-only campaign 44901930871](https://github.com/MoralityLabAI/LoopedTransformers/actions/runs/44901930871) passed all 88 independent new-world native/SAE/geometry auditor jobs and the independent pure-stdlib aggregate. The audited aggregate is artifact **14706609900**, `nec03p-eighty-eight-root-source-recruitment-audited-ledger`.

Each one of the original development roots `dev5-008..095` contains two separately seeded model arms, composed and equal-prior additive. Every arm trained **900 original source updates**, saved/reloaded its byte-hashed model checkpoint and trained **900 further source-only updates with fresh AdamW moments**. A new 128-feature TopK16 SAE was fitted for 480 updates to the reset1800 model's original first 40 complete source groups; 12-visit ranks used the other 40 source groups. When an eligible source candidate existed, an exhaustive source-only angular sham was evaluated on eight original source groups at equal physical 32D output dose. Each root's independent auditor replayed both native checkpoints and original source labels, SAE reconstruction, 40/40 ranks and exhaustive matched-sham directions.

All 88 originally registered roots were retained in the denominator with no early stopping. The observed 69/88 paired admission proportion has an exact 95% Clopper-Pearson interval of approximately **68.4% to 86.5%**, conditional on binomial population assumptions.

Among the 19 paired admission misses, **12 native model arms** fell below the registered 90% in-sample source accuracy requirement and **seven arms** lacked a viable native source candidate/SAE, often due to the frozen nonhub fallback constraint. Every fitted dictionary's source-only directional control passed the predeclared geometry feasibility gate. This additional failure is retained.

The composed branch had **76/88** competent native heads and **74/88** fully source-eligible arms. All **88/88** additive native heads exceeded the 90% source gate; **83/88** additive arms passed full source instrument admission.

## Statistical scope

**A source-eligible root is a prospective instrument recruitment candidate.** This experiment contains **zero causal sham correctness measurements**, so it establishes neither a behavioral 95th-percentile sham tolerance bound nor a causal SAE reasoning effect. The nonparametric 95/95 sample-maximum calibration requires at least 59 independently eligible and exchangeable **causal sham outcome roots** under a separately frozen intervention policy. Root eligibility is conditional on the source model and learned SAE; the full 88-root all-attempted ITT distribution must be preserved when interpreting population-wide mediation.

All 24 original five-input development-evaluation and 24 reserved context groups per world remain unscored. All 32 five-input embargoed worlds and original 64 four-input confirmation worlds are also untouched. The original strict NEC-03N continuous-optimizer failure remains recorded. The source program follows the **distinct** checkpoint-reset optimizer condition.

The source-recruitment prerequisite to planning an independently measured 59-root sham calibration has now been met. A separate [eight-world developmental causal-resolution design](https://github.com/MoralityLabAI/LoopedTransformers/pull/265) has already been merged with its own sealed readout. It is intended to estimate an intervention contrast and matched-sham variation, rather than to confirm a 2-percentage-point population effect under the conservative FSI-01 bound.
