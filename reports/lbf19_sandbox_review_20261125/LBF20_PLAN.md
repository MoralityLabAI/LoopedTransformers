# LBF-20 plan (proposed; no training or new evaluation authorized here)

## Gate 0: repair evaluation semantics

Run same-machine paired eager/deferred verification on all archived LBF-19 roots, all frozen controllers, common wall-time and call deadlines. Separate search, model, initialization, native replay and standalone compile time. Report survival curves and closure at fixed budgets; failures remain censored. Include exact symbolic and native tactic baselines. Complete missing registered count-mode arms, labeled late execution. No post-hoc reinterpretation of the original tests.

## Gate 1: sound graded ground automata

Formalize weighted-run semantics, truncated min-plus saturation and ground completeness/soundness. Test independent subtree rewrites, growth, cycles, erasure of ground subterms and witness reconstruction. Compare exact BFS, unweighted completion and weighted saturation on deliberately hard depth-discrimination examples. Extend only after resolving the variable-copying counterexample. Track peak memory and actual runtime.

## Gate 2: genuine expensive successor search

Choose a Lean tactic domain where the cheap controller does not already know whether the tactic succeeds or what successor it produces (unification, local context changes, conditional rewrites, branching tactics). Expose only the public proof state and permitted action menu. Treat native elaboration/tactic outcomes as environmental observations. Compare strong classical heuristics, learned ranker without envelope, guarded abstraction plus learned readout, exact lookahead where feasible, and deferred replay wherever valid. Measure kernel-checked coverage versus time.

## Gate 3: recurrence factorial

Direct/recurrent x structural prior/no prior, with same hull, training examples, parameter and measured-compute controls. Retain at least ten independent training seeds for architecture-level inference if feasible. Register meaningful effect sizes and root counts. Compare novel-cell AP, word-level false negatives, closure and proof acquisition time. Archive per-fit checkpoints externally with hashes, match draw receipts and model cards; route discovery records to Model Atlas.

## Gate 4: fresh confirmation

Freeze a signed server-timestamped registration and unambiguous beacon seed conversion, then score a fresh untouched cohort exactly once. Treat old exposed cohorts as retrospective. Use claim-specific evidence and report misses.
