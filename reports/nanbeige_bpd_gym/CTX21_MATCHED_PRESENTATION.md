# Prepared CTX21 matched-results presentation

Update: BF16 was interrupted under the RAM policy. Its original terminal audit failed without a normal receipt. The metadata follower correctly ended unrun; this reader has published no matched comparison. Closed native files await a separately registered partial audit.

Prepared while BF16's registered 8K block is still running. The new
[presentation reader](../../mechinterp/nanbeige_bpd_gym/ctx21_results.py)
transcribes the original frozen aggregate. It adds no model call, grade,
geometry calculation, endpoint, fitted dictionary or inferential comparison.
All original source seals, capacity stops and unobserved outcomes remain intact.

The final output has all **96 backend/stratum/loop accuracy rows**, **48
exact-prefix paired correctness rows**, and **576 metric rows from all 96
split/budget/position/arm/layer geometry strata**. It retains both loops,
all main/copy/erased controls, CAL and DEV, 4K and 8K, all position profiles,
both-world root coverage, partial roots, nullable zero-norm metrics, full-roster
unknown-outcome bounds, and allocator peaks. Every scalar remains at its
original JSON precision in CSV; Markdown alone is display-rounded.

The six metrics remain exactly those of the frozen producer: h1 and h2
relative L2/cosine, and h2−h1 displacement relative L2/cosine. Denominators
use BF16 norms; available worlds are averaged within roots, then roots equally.
Root units and repeated measurements remain separate. These are descriptive
development comparisons, not calibrated power, equivalence or causal results.
NF4/BF16 capacity also includes their different decoder placement.

The [metadata handoff](../../mechinterp/nanbeige_bpd_gym/ctx21_results_handoff.py)
holds the original CTX21 supervisor's actual process handle. It can publish
only after **both terminal audits and reports succeed and the final aggregate
is committed**. It verifies private closed receipt/audit hashes against that
committed aggregate, then runs the reader and pushes only the five aggregate
presentation files. It has no model-starting or grading path. Failed/missing
upstream audit/publication leaves the presentation unrun and explicit.
One-thread/Below Normal limits also apply to this small metadata process.

Eight synthetic contracts cover partial roots and missing 8K outcomes,
full-precision CSVs, duplicate/missing strata, invalid geometry and bounds,
premature-publication rejection, the actual CLI's five hash-bound output
files, and successful-publication ordering after both terminal audits.
The first CLI fixture hit a Windows sandbox default-temp permission error;
its temporary directory was moved into a checked workspace child before the
complete suite passed. No model or frozen method was affected. Synthetic
scores never populate the real result filenames in the report collection.
